# CCNA IPv4 원본 연습문항 5개 · 검수용 초안

상태: 콘텐츠 검토 완료, 제품 미게시. 작성: Content 별도 담당. 독립 검토: PO. 확인일: 2026-11-17. 시험: CCNA 200-301 v1.1 및 v2.0. 언어: 한국어 초안. 영역: v1.1 1.6 IPv4 주소/서브네팅 설정·검증, v2.0 1.3 IPv4 주소/서브네팅 문제 해결. 모든 문항은 Quizeey가 만든 연습문항이며 Cisco 공식 기출이 아니다. 아래의 정답 위치는 검수용이며 실제 화면의 보기 회전과 다를 수 있다.

공통 공식 근거: [Cisco v1.1 시험 범위](https://learningcontent.cisco.com/documents/marketing/exam-topics/200-301-CCNA-v1.1.pdf), [Cisco v2.0 시험 범위](https://learningcontent.cisco.com/documents/marketing/exam-topics/200-301_CCNA_v2.0_Exam_Topics_PDF.pdf), [Cisco의 IPv4 주소·서브네팅 설명](https://www.cisco.com/c/en/us/support/docs/ip/routing-information-protocol-rip/13788-3.html). 각 문항의 숫자와 상황은 새로 구성했다.

## 1. 같은 LAN의 게이트웨이 주소 · 쉬움

호스트가 `192.0.2.146/25`로 설정됐다. 호스트의 기본 게이트웨이로 사용할, 호스트와 같은 /25 서브넷의 라우터 인터페이스에 배정할 수 있는 주소는?

1. `192.0.2.129` **정답**
2. `192.0.2.127`
3. `192.0.2.128`
4. `192.0.2.255`

해설: `/25`의 블록은 `192.0.2.128`~`192.0.2.255`이고 일반적인 사용 가능 범위는 `.129`~`.254`다. `.129`는 호스트와 같은 서브넷의 사용 가능한 주소다.

오답 이유: 2는 이전 `/25` 블록의 브로드캐스트 주소다. 3은 현재 블록의 네트워크 주소다. 4는 현재 블록의 브로드캐스트 주소다.

## 2. /22 네트워크 기록 교정 · 보통

장비 주소는 `10.40.7.200/22`인데 관리 기록에는 네트워크가 `10.40.7.0/22`로 적혀 있다. 올바른 네트워크·브로드캐스트 주소 쌍은?

1. `10.40.4.0` / `10.40.7.255` **정답**
2. `10.40.7.0` / `10.40.7.255`
3. `10.40.8.0` / `10.40.11.255`
4. `10.40.4.0` / `10.40.4.255`

해설: `/22`는 `255.255.252.0`이므로 세 번째 옥텟이 4씩 증가한다. `7`은 `4`~`7` 블록에 속한다.

오답 이유: 2는 `/24`처럼 세 번째 옥텟 `7`을 네트워크 경계로 간주한다. 3은 다음 `/22` 블록이다. 4는 브로드캐스트를 한 `/24` 범위에서 끊었다.

## 3. 서로 다른 마스크의 로컬 판단 · 보통

같은 LAN의 A는 `192.0.2.126/27`, B는 `192.0.2.130/24`다. 각 장비가 **자신의 마스크만 기준으로** 상대 주소를 같은 서브넷으로 판단하는가?

1. 둘 다 같은 서브넷으로 판단한다.
2. A는 다른 서브넷, B는 같은 서브넷으로 판단한다. **정답**
3. A는 같은 서브넷, B는 다른 서브넷으로 판단한다.
4. 둘 다 다른 서브넷으로 판단한다.

해설: A의 `/27` 블록은 `.96`~`.127`이어서 B의 `.130`은 밖이다. B의 `/24` 블록은 `.0`~`.255`이므로 A의 `.126`은 안이다. 이 문제는 각 장비의 주소 판단만 묻고 실제 통신 성공 여부는 단정하지 않는다.

오답 이유: 1은 A의 좁은 범위를 무시한다. 3은 판단 방향을 뒤집었다. 4는 B의 `/24` 범위를 무시한다.

## 4. /30 링크 주소 교정 · 보통

일반적인 `/30` IPv4 지점 간 링크에서 R1이 `198.51.100.41/30`, R2가 `198.51.100.43/30`으로 설정됐다. 주소만 수정한다면 R2에 배정할 주소는?

1. `198.51.100.42/30` **정답**
2. `198.51.100.40/30`
3. `198.51.100.43/30`
4. `198.51.100.44/30`

해설: 블록은 `.40`~`.43`이다. `.40`은 네트워크, `.43`은 브로드캐스트이며 일반적인 사용 가능 주소는 `.41`과 `.42`다.

오답 이유: 2는 네트워크 주소다. 3은 현재 잘못 설정된 브로드캐스트 주소다. 4는 다음 `/30` 블록의 네트워크 주소다. `/31` 지점 간 링크의 별도 규칙은 이 문제에 적용하지 않는다.

## 5. 겹치지 않는 서브넷 재할당 · 어려움

`10.0.8.0/24` 안에서 LAN A가 `10.0.8.0/25`를 사용한다. LAN B는 일반적인 사용 가능 호스트 주소 **50개 이상**이 필요하다. LAN A와 겹치지 않고 이 조건을 만족하는 LAN B의 서브넷은?

1. `10.0.8.128/26` **정답**
2. `10.0.8.64/26`
3. `10.0.8.128/27`
4. `10.0.8.0/26`

해설: LAN A는 `.0`~`.127`을 점유한다. 1은 `.128`~`.191`이므로 겹치지 않고 `/26`의 일반적인 사용 가능 주소는 62개다.

오답 이유: 2와 4는 LAN A 범위와 겹친다. 3은 겹치지 않지만 `/27`의 사용 가능 주소가 30개라 부족하다.

## 검토 기록과 게시 조건

- 작성자는 Cisco 공식 범위와 주소 계산 근거를 확인했다. 독립 검토자는 다섯 계산을 다시 확인하고 기존 2026-10 CCNA 23문항의 질문을 모두 대조했다. 기존 세트의 `/27` 호스트 수, `/26` 마스크·사용 범위와 정확히 같은 질문·주소 예제를 반복하지 않는다. 기존 한국어 글의 `/26`·`/23`·`/28` 주소 사례도 반복하지 않는다.
- 검수 결론은 문항 내용 초안에 한정한다. 현재 제품의 CCNA 2026-10 세트는 영어이며, 한국어 문항의 등록 방식·보기 회전·저장 점수·중복 식별자·실제 렌더링과 회귀는 검증되지 않았다. 이 문서를 공개 제품에 연결하거나 문항 데이터에 넣기 전에 콘텐츠 revision과 실제 연습 경로를 정하고 독립 회귀를 완료해야 한다.
