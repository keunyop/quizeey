# 한식조리 가식부 수율 글·확인 문제 검수

- 대상: [가식부 수율 글](../../web/src/components/CookingYieldArticle.tsx), 한국어, 한식조리기능사 학습용 개념 사례. 한국 공식 기출문제나 특정 출제 범위의 보증이 아니다.
- 제작일/개정: 2026-11-23, `cooking-yield-v1`. 주제는 손질 후·조리 전 가식부량, 수율/손실률, 구입량 역산, 온전한 인분 수 계산이다. 세 문항은 글 안 확인 문제이며 기존 11월 회차의 문항을 수정·등록하지 않는다.
- 역할: primary 작성·통합·실제 로컬 경로/검사, `content_research` 기존 수요/공식 원천 조사(문항 작성 없음), `independent_review` 별도 사실·문항·오답·코드 검수. 최종 검수 결과는 아래에 추가한다.

## 근거와 원본성

공식 자료는 [USDA Food Buying Guide Introduction PDF](https://foodbuyingguide.fns.usda.gov/Content/TablesFBG/USDA_FBG_Introduction.pdf), 2026-11-23 확인이다. 인쇄 I-20은 AP/EP 정의, I-48 Method 3는 준비에 필요한 양을 수율로 나누는 구입량 역산, I-5는 수율 변동 요인을 설명한다. 원본 예제의 재료·단위·수치를 복제하지 않고 투명한 가정 중량과 비율을 사용했다. 실제 채소마다 같은 수율이 적용된다는 주장은 없다.

기존 위생·감염 경로 글과 주제를 비교했다. 한국 필터 GSC의 필기 연습 의도와 실제 한식 연습 경로가 선정 근거이며 좁은 수율 검색 수요와 같은 방문의 전환은 미측정이다. 원본 지표·입력 식별자는 비공개 조사 기록에만 보존한다. 관련 계산이 기존 11월 자체 제작 회차에도 있어 개념 중첩은 있지만 이 글의 중량·배합 조건·오답 구성은 새로 작성했다.

## 검증·관측

별도 검수자는 한국 필터 GSC/후속 원본과 공식 USDA PDF를 직접 읽고 최종 본문·세 정답·모든 오답·가정률·단계/단위·등록·React 품질·브라우저 명세를 대조했다. 내용/코드 결함은 발견하지 않았다. 첫 전체 검사의 기존 사이트맵 날짜 기대값 실패는 정상 갱신 후 재검수·전체 재실행 대상으로 유지한다. 최종 검사 영수증 대조와 독립 승인 전 출시는 대기한다.

실제 로컬 한식조리 11월 경로에서 첫 수율 문제·네 보기·75% 정답 제출·계산 해설을 확인했다. 회차 전체80/기본 화면20 경계도 확인했다. [브라우저 회귀](../../web/e2e/cooking-yield-blog.spec.ts)는 블로그 목록→글/세 해설→정확한 회차→답 제출/해설과 JS 없는 읽기·모바일 양 테마·접근성을 검증한다. 전체 검사 결과와 독립 검수 완료 전에는 게시하지 않는다.

운영 읽기 확인 다음 날부터 완결28일 GSC 글/검색어와 GA4 한식 학습 시작을 분리 관측한다. 속성/시험별 수신/확정 범위를 확인하기 전 효과·인과 전환율은 미측정이다. 최종 출시/검증은 [일지](../quizeey-ops/journal/2026-11-23.md)를 따른다.

최종 코드의 전체 로컬 검사는 종료 0으로 타입·lint·단위190·빌드·브라우저151·모의 광고6이 한 회차에서 모두 통과했다. 격리 DB/Auth 포함, 테스트 생략0, 실제 외부 광고 요청0이다. fixture 빌드의 운영 자격증명 preflight 생략은 테스트 생략과 구분한다. 후속 입력 준비 가드의 독립 원인 재현·검수·두 언어 지연 회귀와 실제 출시/최종 승인 상태는 일지에 연결한다. 원래 실패한 전체 실행을 통과 실행과 합산하지 않았다.
