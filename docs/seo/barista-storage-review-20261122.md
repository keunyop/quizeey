2026-11-22 공식 원문: [NCA Storage and shelf life](https://www.aboutcoffee.org/beans/storage-and-shelf-life/), [SCA What is “freshly roasted” coffee?](https://sca.coffee/sca-news/coffee-decoded-9-fresh-coffee). 작성자와 독립 검수자가 원문을 각각 읽는다. 보관 조건 비교는 학습용 가정이며 실험 결과로 쓰지 않는다. 특정 신선도 일수·안전 기한·크레마만으로 품질 확진·냉장/냉동 절차·협회 자격시험 보증을 주장하지 않는다.

기존 [추출 비율·분쇄도 글](../../web/src/components/BaristaExtractionArticle.tsx)은 1:2 계산과 물 흐름·채널링을 설명한다. 이번 글은 보관 배치·분쇄 시점·디개싱과 산화를 중심으로 새 사례와 보기로 작성했다. 같은 기초 개념을 다룬다는 사실을 전체 인터넷에서 유일한 문항이라는 주장으로 바꾸지 않는다.

실제 로컬 `/barista-2?verNbr=202611`에서 바리스타 2급 제목·11월 자체 제작 20문항·첫 분쇄저항 문항과 네 선택지를 확인했다. 20문항 전체로 연결하며 보관 문제만 모은 세트나 본문 세 문제의 신규 등록을 약속하지 않는다. JavaScript 비활성 읽기·모바일 양 테마 접근성·정확한 연습 연결·답 제출/해설은 [로컬 회귀](../../web/e2e/barista-storage-blog.spec.ts)와 전체 검사로 확인하며 실제 실행 결과는 일지를 따른다.

원본 지표·검색어·출처 식별자는 비공개에 보관한다. 한국의 바리스타 학습 의도와 별도 페이지 근거를 사용하며 보관 전용 검색 수요나 동일 방문 전환은 미측정이다. 11월 22일 운영 확인 시 11월 23일~12월 20일 완결 28일 동안 GSC와 GA4를 분리 관측한다. 복구는 글·등록·연결 변경의 Git revert다.
