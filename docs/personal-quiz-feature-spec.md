**Quizeey 개인 문제집 생성·학습 기능 최종 설계서**

작성일: 2026-11-03  
상태: 사용자 협의를 반영한 개발 전 제품·화면·동작 명세. 구현 및 배포는 시작하지 않았다.  
적용 서비스: Quizeey 한국어·영어 사이트.

**1. 사용자의 학습 자료에서 AI가 새로운 문제를 만들어 개인 문제집으로 저장한다.**

Quizeey는 무료 공개 문제풀이를 제공하면서, 회원에게 개인 자료 기반 문제 생성과 학습 기능을 추가한다. 기존 시험 목록·한 문제씩 풀기·정답 확인·해설·오답 및 북마크 복습 경험을 개인 문제집으로 확장한다.

RubriCheck의 과제 채점·루브릭·프로젝트 구조를 가져오지 않는다. 사용자는 자료를 올리거나 텍스트를 붙여넣고 바로 문제집을 만들 수 있다. Quizeey에 등록되지 않은 시험이나 자유 주제도 사용할 수 있다.

| 결정 항목 | 사용자와 확정한 내용 |
|---|---|
| 생성 기능 범위 | AI로 새로운 연습문제 생성. 이미 문제와 정답이 들어 있는 PDF를 그대로 문제집으로 변환하는 기능은 초기 제외 |
| 상품 구조 | 충전형과 월 구독 병행 |

개인 자료 업로드·생성·문제집 풀이에는 무료 회원도 광고를 표시하지 않는다. 구매한 충전량은 만료 없이 유지하고, Plus 이용 중에는 차감하지 않는다. 구독이 끝나도 남은 충전량과 기존 문제집을 계속 이용할 수 있다. 초기에는 충전팩 한 종류와 월 구독만 제공한다.

이 문서의 파일 크기·1회 생성 수·동시 작업 수·인증번호 유효기간은 구현을 위한 초기 설계 기본값이다. 이를 사용자와 확정한 요금이나 월 생성량 정책으로 혼동하지 않는다. 실제 구현 검증으로 운영 기본값을 조정할 수 있지만, Plus에 일별·월별 문항 총량 제한을 추가하지 않는다.

**2. 기존 서비스와 새 기능의 역할을 명확하게 구분한다.**

확인한 현재 구조에서는 공개 문제풀이의 진행·답변·북마크·즐겨찾기를 브라우저에 저장하며 일반 회원용 결제·구독 흐름은 없다. 새 기능에는 회원 계정, 개인 문제집 보관, 생성 이용량, 결제와 구독 권한 관리가 필요하다.

- 기존 공개 문제는 로그인 없이 계속 이용한다. 로그인 요청으로 기존 문제풀이를 막지 않는다.
- 개인 문제집과 해당 풀이 기록은 계정에 저장해 여러 기기에서 이어서 학습한다.
- 초기 계정 동기화 범위는 개인 문제집이다. 기존 비회원 공개 문제풀이 기록은 현재 브라우저에 유지하며, 회원가입만으로 자동 이전하거나 삭제하지 않는다. 공개 기출 기록 전체의 기기 간 동기화는 후속 범위다.
- 개인 생성 문제는 기존 공개 시험 문제 목록에 자동 등록하지 않는다. ‘AI 생성 연습문제’와 공개 시험 콘텐츠의 출처를 구분한다.
- RubriCheck 계정·무료 생성량·구독·크레딧과 연동하지 않는다. RubriCheck Pro나 평생 이용권을 Quizeey Plus로 인정하지 않는다.
- Quizeey에는 초기 연간 구독·평생 이용권·다단계 유료 등급을 추가하지 않는다.

**3. 단순한 탐색과 기존 Quizeey 디자인을 사용한다.**

현재 밝은 배경과 흰색 영역, 파란 강조색, 얇은 구분선, 작은 둥근 모서리, 라이트·다크 테마를 재사용한다. 별도 브랜드 색상이나 RubriCheck형 고정 사이드바를 추가하지 않는다.

데스크톱 상단 탐색은 ‘시험 목록 / 내 문제집 / 요금 / 로그인’으로 구성한다. 로그인 후에는 로그인 자리에 계정 메뉴를 두고 이용량·결제 관리·로그아웃을 제공한다. 기존 언어 선택과 테마 변경은 유지한다.

모바일에서는 로고와 주요 진입점·메뉴만 상단에 두고, 요금·계정·언어·테마 항목은 메뉴 안에 정리한다. 개인 문제집은 한 열, 문제 풀이는 기존 Quizeey처럼 본문 중심으로 제공한다.

- 한 화면의 주 버튼을 하나로 강조한다. 제목이나 버튼으로 충분한 행동을 문단으로 반복 설명하지 않는다.
- 개인 문제집은 간결한 목록을 사용한다. 현황 카드 여러 개, 큰 통계 대시보드, 장식용 배너, 반복되는 AI 배지나 축하 팝업을 추가하지 않는다.
- 사용자에게 필요한 잔여량·출제 범위·원문 만료·오류는 해당 위치에서 짧게 알린다. 핵심 정책을 숨겨 단순하게 보이도록 하지 않는다.
- 해설은 학습 내용이므로 필요한 설명을 제공한다. 줄이는 대상은 제품 안내와 중복 문구다.
- 기존 색상 토큰과 버튼·입력 요소를 사용하고, 주요 터치 요소는 최소 44px 높이를 유지한다. 정오답·선택 상태를 색만으로 전달하지 않는다.
- 생성·풀이 화면에 홍보 문구, SEO 문단, 모델·저장 방식 등 구현 설명을 넣지 않는다.

| 공개 기능 소개 | `/ai-quiz-generator` | 누구나 |

- 제목을 누르면 문제집 상세에서 자료명·출제 범위·생성일·문제 유형·풀이 기록을 확인한다. 문제와 해설을 먼저 보고 학습하는 것도 가능하다.
- 기존 진행이 있으면 ‘계속 풀기’, 풀이가 없으면 ‘시작하기’, 완료했으면 ‘다시 풀기’를 제공한다.

- 문제집은 필수 폴더 없이 바로 만든다. 기존 시험 연결은 선택사항이며 목록에 없는 시험·과목은 자유롭게 입력할 수 있다.
- 원문 만료는 ‘자료 만료’로 표시한다. 생성된 문제집 자체가 만료되거나 풀이 불가능한 것처럼 표시하지 않는다.
- 생성 중 작업과 실패 작업을 구분해서 확인할 수 있게 한다. 완료된 문제집 목록과 동일한 학습 상태로 취급하지 않는다.
- 빈 화면에는 ‘아직 문제집이 없습니다’와 ‘문제집 만들기’만 표시한다.
- 생성량을 다 쓴 회원도 목록·해설·재풀이는 이용한다. 구매 안내는 새로운 생성에 필요한 지점에 둔다.

**5. 자료 선택과 설정을 한 페이지에서 완료한다.**

```text
[← 내 문제집]                        문제집 만들기

[파일 업로드] [텍스트 붙여넣기]

자료
네트워크 요약.pdf                 18쪽   [삭제]
[＋ 자료 추가]

문항 수        [10] [20 ✓] [50]
난이도         [기초] [보통 ✓] [심화]

추가 설정 ▾
출제 범위 / 문제 언어 / 시험·과목

문제집 이름    [네트워크 핵심 개념             ]

무료 20문항 남음 · 이번 생성 20문항
                                      [문제 만들기]
```

- 교과서, 강의 슬라이드, 개인 노트, 과제, 기타 학습 자료를 받는다. 과제 채점이나 루브릭을 요구하지 않는다.
- 파일과 붙여넣은 텍스트를 여러 개 결합할 수 있다. 업로드 전에 가입·로그인을 완료해야 한다.
- 자료에서 새 연습문제를 만드는 기능이다. 기존 문제 PDF를 원문 문항·보기·정답 그대로 가져오는 기능으로 소개하지 않는다.
- 문제집 이름은 자료명과 주제를 이용해 제안하고 사용자가 수정할 수 있다.
- 기본값은 4지선다, 20문항, 보통 난이도, 현재 UI 언어다. 초기 UI와 문제 언어는 한국어·영어를 지원한다.
- 사용 가능한 무료·구매 문항 수가 20개보다 적으면 잔여량을 기본값으로 한다. 1–50문항 사이에서 선택할 수 있게 하고 10·20·50을 빠른 선택으로 제공한다.
- 무료 잔여량과 구매 잔액을 함께 쓸 수 있다. Plus에서는 잔여량 숫자 대신 ‘Plus · 생성량 무제한’을 표시한다.
- 추가 설정은 기본적으로 접는다. 긴 자료가 처리 상한을 넘으면 출제 범위 선택을 자동으로 펼쳐 사용자가 범위를 고르게 한다.
- PDF는 페이지, PPTX는 슬라이드, DOCX와 TXT는 제목·문단·텍스트 범위를 선택한다. 불확실한 DOCX 페이지 번호를 임의로 만들지 않는다.
- 선택한 전체 자료와 범위를 생성 버튼 위에 확인할 수 있게 한다. 자료 일부만 처리했을 때 전체 문서를 읽었다고 안내하지 않는다.
- 자료의 미리보기를 제공하고, 인식이 어려운 스캔이나 읽을 수 없는 부분을 표시한다. 실패한 자료를 조용히 빼고 생성하지 않는다.
- 원문 보관 안내는 ‘자료 7일 보관 · 만든 문제집은 계속 이용’처럼 짧게 한 번 표시한다.

**6. 자료 처리와 한 번의 생성에 운영 상한을 둔다.**

| 항목 | 초기 설계 기본값 |
|---|---|
| 지원 파일 | PDF, DOCX, PPTX, TXT, PNG, JPG, JPEG |
| 선택 자료 | 요청당 최대 5개. 붙여넣은 텍스트도 자료 하나로 계산 |
| 파일 용량 | 파일당 20 MB, 요청에 올리는 파일 합계 50 MB |
| 처리 범위 | 선택 범위 합계 50페이지·슬라이드·이미지 이내이면서 추출 텍스트 합계 50,000자 이내 |
| 문항 수 | 요청당 1–50문항, 기본 20문항 |
| 동시 생성 | 계정당 1개 작업 |
| 자료 보관 | 접수 완료부터 7일, 사용한다고 자동 연장하지 않음 |
| Plus 생성 총량 | 일별·월별 문항 수 한도 없음 |

이는 한 요청의 크기와 처리를 안정적으로 유지하기 위한 값이다. Plus 월 총량 제한이나 별도 유료 추가 처리량으로 사용하지 않는다. 상한은 업로드·생성 전에 표시한다.

긴 교과서는 필요한 챕터·페이지를 선택한다. 업로드 용량을 초과하면 해당 부분을 나누어 올리도록 안내한다. 비밀번호로 잠긴 파일, 미지원 형식, 판독 불가 자료는 오류와 해결 방법을 표시한다. OCR·수식·표·코드·그림을 정확하게 읽을 수 없으면 내용을 추측해 출제하지 않는다.

**7. 선택한 유형과 자료에 맞는 문제를 생성한다.**

| 선택 | 생성 결과 |
|---|---|
| 4지선다 | 네 선택지, 단일 정답의 객관식만 생성 |
| O/X | 하나의 명제를 맞다·틀리다로 판단하는 문제만 생성 |
| 혼합 | 두 유형을 자료와 학습 목적에 맞게 조합 |

- 혼합은 객관식 60–80%, O/X 20–40%를 출발점으로 삼되 고정 비율로 강제하지 않는다. 실제 구성을 완료 화면에 표시한다.
- 혼합에서 2문항 이상이면 두 유형을 포함하는 것을 기본으로 한다. 자료상 한 유형을 억지로 넣으면 품질이 떨어지는 경우는 한 유형을 허용한다. 1문항이면 적절한 유형 하나를 선택한다.
- 4지선다는 정답이 하나여야 한다. 중복·무의미한 오답, 답이 여러 개인 문항, 선택지 길이나 표현만으로 답이 드러나는 문항을 피한다.
- O/X는 판단 가능한 진술 하나를 사용한다. 애매한 부정문이나 여러 독립 주장을 한 문장에 묶지 않는다. 틀린 진술의 해설에는 올바른 내용을 설명한다.
- 영어 화면에서는 O/X를 True/False로 표시한다. 의미를 색상이나 기호만으로 전달하지 않는다.
- 서술형, 자유 답변, 복수 정답, 5지선다, AI 답안 채점은 초기 새 문제 생성 범위에 포함하지 않는다. 기존 공개 문제의 다른 유형은 기존대로 동작한다.
- 선택한 시험·과목은 분류와 출제 맥락에 사용한다. 시험을 선택했다는 이유로 공식 출제 기준을 완전히 반영한 문제라고 보장하지 않는다.

각 문항은 질문, 유형, 선택지, 정답, 해설, 개념 태그, 출처 자료와 위치를 보관한다. 정답 근거와 핵심 오답 이유를 설명하고, 읽은 자료 안에서 뒷받침할 수 없는 사실은 임의로 추가하지 않는다.

업로드 자료를 검증된 정답집으로 취급하지 않는다. 명백한 오류·상충된 설명·불충분한 근거가 있으면 해당 문항을 제외하거나 추가 자료가 필요함을 안내한다. 자료가 부족할 때 요청 수를 맞추려고 비슷한 문제를 반복하거나 불확실한 답을 만들지 않는다.

출처는 실제 확인 가능한 파일과 페이지·슬라이드·문단에 연결한다. 생성 결과에서 정답 유일성, 근거와 해설의 일치, 중복, 선택 범위 준수, 유형 구성을 확인한다. 사용자 파일에 있는 명령문으로 시스템 동작이나 권한을 바꾸지 않는다.

- 실패한 작업은 무료·구매 문항을 차감하지 않는다. 설정을 유지하고 유효한 자료로 재시도할 수 있다.
- 같은 작업의 새로고침·재전송·응답 복구로 중복 문제집이나 중복 차감이 발생하지 않는다.

16. 공개 기능 소개·요금·실제 권한이 일치하고, 공개 SEO와 개인 noindex·소유권 보호가 함께 동작한다.
