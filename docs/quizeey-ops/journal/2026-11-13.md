- 로컬 report 입력함의 기존 15개 원본은 처리 manifest의 체크섬 또는 기존 동일 체크섬 별칭과 일치한다. 신규 파일은 없고, 기존 GA4 행 합계 차이·원천 확정일·시험별 학습 시작의 검증 공백은 남아 있다.

- `master`는 `origin/master`보다 운영 문서 커밋 하나 앞서 있고, PO 스킬과 참조 자료에 기존 미커밋 변경이 있다. 해당 작업은 이번 변경과 구분해 보존한다.
- 오늘의 최우선 작업은 신규 문항 신고의 독립 근거 검증이다. 현재 운영 문항은 해설·출처가 비어 있어, 정답·질문 문구·선택지·연관 문항·저장 점수 영향을 함께 확인한다. 근거 없이 신고만으로 정답을 바꾸거나 해결 처리하지 않는다.
- 담당: PO/Content가 원문과 학습 영향을 확인하고 Engineering이 최소 교정과 로컬 검증을 담당한다. 별도 검수자는 원천 근거, 정답·오답 이유와 변경 diff를 확인한다.
- 완료 기준: 정답 오류 여부를 신뢰할 수 있는 원천과 현재 문제 데이터로 판정한다. 오류가 확인되면 설명 가능한 최소 교정을 준비하고 독립 검수 및 전체 `npm run check:local`을 통과한다. 운영 반영 시 Git `master` push 한 번과 영향 경로의 작은 읽기 확인 후에만 신고를 해결 상태로 옮긴다.
- 기대 결과는 정답 정확성과 학습자 혼란 감소다. 실제 피해 인원·학습 성과는 미측정이다. 운영 변경이 필요하면 검증된 이전 커밋으로 해당 교정을 되돌린다.
- 병행 작업: OPS-06 양식조리 경로의 시험 ID·문항 자료를 조사하고, 오늘 한 편의 원본 글을 기존 검색 의도·실제 연습 경로·공식 근거로 선정한다. 글은 독립 콘텐츠 검수와 필수 로컬 검사가 통과할 때만 게시한다. 글의 검색 클릭·랜딩·학습 시작은 게시 뒤 28일 동안 원천별로 관찰한다.

## 진행 기록

- 신규 신고 문항은 운영 DB에서 현재 문항과 네 선택지를 읽어 확인했다. 보기에는 조리·빙점·석쇠 부착 관련 표현이 있어 외부 근거 대조가 필요하다. 아직 정답 오류로 판정하지 않았다.
- OPS-06 원천 보관 자료와 현재 경로 계약을 대조했다. 양식·일식·중식·복어 경로 네 개는 모두 한식 시험의 문항을 보여 준다. 별도의 해당 시험 ID나 검수된 문항 세트는 확인되지 않았다. 경로 네 개의 학습 기록·세션도 한식과 공유되며 해당 경로의 파생 월별 페이지를 포함한 36개 URL이 사이트맵에 노출된다.
- OPS-06의 안전한 최소 교정안은 기존 URL을 정확한 안내 페이지로 유지하면서 잘못된 문제풀이를 막고 시험 목록·사이트맵·검색 색인에서 제외하는 것이다. 한식 문제풀이는 명시적으로 따로 연결하고, 기존 학습 기록을 삭제하거나 출처 없는 시험 ID를 새로 할당하지 않는다. 이는 여러 경로와 SEO에 영향을 주므로 별도 변경·검증 대상으로 남긴다.
- 오늘 글의 주 검색 의도는 한국의 `SQLP 기출문제`·`SQLP 문제`로 선택했다. 기존 GSC 검색어·연습 페이지에는 클릭이 있고 GA4 랜딩에는 세션이 있으나 원천 확정일과 행 합계 차이 때문에 성장 효과를 확정할 수 없다. 최근 글이 있는 SQLD·3D·CCNA·한식, 잘못 연결된 양식, 검색 근거가 작은 해외 경로는 대안에서 제외했다.
- 로컬 `dev:local`의 `/sqlp-professional?verNbr=202611`에서 SQLP 시험 제목과 11월 B-tree 문항을 실제 HTML로 확인했다. 기존 SQLD 글은 COUNT/NULL을 다루며 이번 실행계획 사례와 중복되지 않는다. DataQ의 SQLP 종목 안내와 PostgreSQL 17의 EXPLAIN·표현식 인덱스·다중 열 인덱스 공식 문서를 확인했다.
- 글은 원본 SQLP 학습 사례로 작성하며 공식 기출문제나 특정 실행계획을 보장한다고 표현하지 않는다. 게시 뒤 28일 동안 해당 글의 GSC 클릭, GA4 자연검색 랜딩, SQLP 학습 시작을 각 원천에서 분리해 관찰한다. 필수 검사 실패 시 완성 초안을 보관하고 게시하지 않는다.
- 문항 독립 검토자는 같은 선택지와 ④ 정답이 표시된 기출 보관본을 직접 읽어 확인했다. ‘빙점 강화’는 빙점 강하의 부정확한 옛 표현이며, 석쇠 부착 방지는 예열·기름칠이 근거 있는 방법이다. 정답 키와 과거 문구는 유지하고 해설·출처만 보완하는 제안을 비공개 작업 기록에 남겼다. 운영 DB 수정과 신고 해결은 승인 전 실행하지 않는다.
- SQLP 글 독립 검토에서 `EXPLAIN`의 예상값과 실제 쿼리를 실행하는 `EXPLAIN ANALYZE`를 명확히 구분하도록 수정했다. 블로그 메타데이터·접근성·자바스크립트 없는 실제 문제 이동 검사를 추가했고 검토자가 수정본을 다시 확인했다.
- PostgreSQL/Auth 격리 fixture를 켠 `npm run check:local`에서 타입검사, lint, 단위 183개, 빌드는 통과했다. 새 글의 모바일 접근성 및 SQLP 실제 문제 이동 검사는 통과했다. 기존 California 150문항 전체 학습 브라우저 테스트 한 건이 실패해 원인과 최종 전체 결과를 확인 중이다. 전체 필수 검사 통과 전 게시하지 않는다.
- 첫 검증에서 150문항 테스트는 120초 제한에 걸렸고, 인기순 테스트는 다른 테스트의 클릭 누적으로 SQLD가 첫째라는 가정이 깨졌다. 장시간 테스트 제한을 180초로 늘리고 인기순 검사는 fixture에서 일시적으로 선두 조회 수를 설정·복원해 결정적으로 검증하도록 수정했다. 새 격리 DB/Auth fixture로 `npm run check:local`을 처음부터 다시 실행했다. 종료 코드 0; 타입검사, lint, 단위 183개, 빌드, 브라우저 116개, 광고 검사 통과. DB/Auth 테스트는 건너뛰지 않았다. 포트 3100·55432·55433의 서버 종료를 확인했다.
- 최종 스테이징 12개 파일은 별도 검토자가 읽기 전용으로 다시 확인했다. SQLP 슬러그·실제 11월 시험 ID와 문항, 메타데이터·사이트맵·CTA가 일치하고, 두 테스트 수정은 현재 단일 브라우저 워커에서 타당하다. 비공개 신고 식별자·지표·자격증명 유출이나 출시 차단 결함은 발견되지 않았다. 기존 사용자 스킬 편집 파일과 무시되는 비공개 작업 기록은 스테이징에서 제외했다.
