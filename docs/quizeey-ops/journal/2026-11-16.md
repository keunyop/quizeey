## 시작 상태와 선택
- 11월 15일 조리 시험 경로 교정과 메이크업 글은 비공개 배포 영수증에서 production READY 및 영향 경로 읽기 확인이 끝났다. 효과는 아직 관측 대기다. 전날의 일지·보고서·공개 상태에는 미커밋 정합화 변경이 있으므로 보존하고 검토 후 함께 처리한다.
- 마지막 처리 목록에는 11월 15일 GA4 일별·학습 이벤트와 GSC 보고서가 검증 제한을 명시한 채 반영됐다. 오늘 입력함의 새 파일 여부, 운영 DB의 열린 신고, legacy GitHub 열린 이슈를 다시 확인한다. 수치와 원본 식별자는 비공개 기록에만 둔다.
- 오늘 선택: 기존 SQLD 가이드에서 실제 SQLD 연습으로 이어지는 경로를 로컬 fixture로 확인하고, 확인된 불편만 작은 수정으로 처리한다. 일일 원본 글은 중복 여부·검색 근거·실제 문항·공식 출처를 확인한 뒤 별도 콘텐츠 검수와 로컬 검사를 통과해야 게시한다. 우선순위가 더 높은 신규 신고가 나오면 먼저 처리한다.
- 담당: PO는 우선순위와 증거를 통합하고, Engineering은 로컬 경로·접근성·검증, Content는 원본 글과 근거, Data는 입력 자료와 측정 한계, Trust는 신고 분류를 맡는다. 중요한 코드 및 공개 문항은 별도 증거 기반 검토를 완료해야 한다.
- 완료 기준: 신규 신고를 누락 없이 분류하고, 실제 SQLD 시험·문항·CTA 경로를 확인해 필요한 최소 변경을 검증한다. 오늘 글은 검증된 검색 의도와 실제 학습 경로에 연결하고 공식 근거·독립 검수·`npm run check:local`을 통과한다. DB/Auth fixture가 생략되면 명시한다. 예상 지표는 대상 글의 GSC 검색 유입과 GA4 연습 시작이며 `test_id` 수신이 확인되기 전 시험별 전환율은 미측정이다.
- 범위와 복구: 로컬 fixture만으로 회귀 검사한다. 검증된 routine 저위험 변경만 `master` Git push 한 번으로 출시하고, production READY와 영향 경로의 소수 읽기 확인을 남긴다. 실패한 필수 검사는 출시를 막는다. 복구는 해당 글·CTA의 Git 변경 되돌리기다. 운영 DB 변경·신고 조치·외부 발신·신규 지출은 이번 범위에 없다.

## 진행 기록
- 시작 상태 기록 완료. 다음 단계: 입력함·신고함·기존 글과 실제 로컬 풀이 경로를 대조한다.
- 처리 manifest의 체크섬과 입력함 파일을 대조해 새 업로드가 없음을 확인했다. 운영 DB의 문항·피드백 및 댓글 신고는 모두 해결 상태이고 열린 항목은 없다. legacy GitHub 검색에서 기존 48건과 같은 범위의 열린 이슈를 확인했다. 검색 도구가 수정 시각을 제공하지 않으므로 본문 변경 부재까지 단정하지 않는다. 운영 신고 조치는 하지 않는다.
- 지난 분석의 GSC Web 전체기간 표에 `sqld 기출문제 cbt` 검색어와 기존 SQLD 가이드 페이지의 관측이 따로 있다. 두 행을 같은 방문으로 연결하지 않고, 총계 불일치를 유지한다. 기존 COUNT 글과 중복되지 않는 문제는 `WHERE`의 행 필터와 `HAVING`의 그룹 필터 차이다. SQLD/SQLP 이외 후보와 최근 글의 중복을 대조했다. 세부 검색어의 직접 수요나 글→학습 전환은 미확인이다.
- 로컬 fixture에서 기존 가이드의 연습 CTA가 본문 뒤에만 있는 것을 확인했다. `/sqlp-developer?verNbr=202611` 화면은 실제 SQLD 시험명, 2026-11 원본 연습 20문항, 집계 조건 관련 문항을 표시한다. 원본 콘텐츠에서도 시험 ID와 문항을 대조했다. 공식 PostgreSQL 18 문서의 WHERE 및 GROUP BY/HAVING 설명을 확인했고, 작성 글의 주문 예시는 새로 구성했다.
- 서로 연결된 작은 범위를 `feat/20261116-sqld-learning-flow`에서 준비한다: 기존 가이드 초반의 명시적인 11월 연습 링크와, WHERE/HAVING의 계산 사례·오답 이유가 있는 오늘의 원본 글. 검색·학습 효과는 배포 후 완결 28일을 관찰하되 `test_id` 수신 확인 전 시험별 전환율 주장은 하지 않는다. 별도 콘텐츠 검수와 필수 로컬 검증 전에는 출시 후보가 아니다.
- 글 선택 근거의 기간은 Owner GSC Web 차트의 2026-08-14~11-13이다. 검색어 `sqld 기출문제 cbt`와 기존 가이드 페이지를 각기 다른 차원에서 관측했다. 첫 개선은 기존 가이드의 연습 진입이고, 오늘의 별도 글은 COUNT 대신 집계 전·후 조건이라는 다른 문제를 해결한다. 최근 조리·메이크업·바리스타·SQLP·CCNA 글 주제의 반복과, 검증되지 않은 다른 나라의 수요 가정은 피했다. 새 글은 `/blog/sqld-where-having-group-by`, 실제 연습은 `/sqlp-developer?verNbr=202611`이며 PostgreSQL 18 공식 WHERE/GROUP BY·HAVING 설명을 원리 근거로 사용했다.
