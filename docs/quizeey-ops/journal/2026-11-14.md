# 2026-11-14 Quizeey PO 일지

## 시작 상태와 오늘 선택

- 목표: GA4의 Vancouver 날짜 기준 일별 활동 사용자 1,000명. 현재 자료의 최신 완결일과 속성 연결은 확인되지 않아 목표 격차는 비공개 기준선에서만 계산하고 공개 성과로 단정하지 않는다.
- 로컬 report 입력함의 15개 원본은 모두 처리 manifest의 체크섬과 일치했다. 새 업로드는 없다. GA4의 표시 총계와 차원 행 합계 차이, 원천별 확정일, 시험별 학습 시작과 재방문 계측 공백은 남아 있다.
- 읽기 전용 운영 DB 재조회에서 열린 문항·댓글 신고는 없었다. 전날 열려 있던 문항 신고는 이 실행 이전에 관리자 해결 감사 기록과 함께 `resolved`가 됐다. 정답·표현의 역사적 모호성은 별도 콘텐츠 검토 과제로 유지한다. legacy GitHub 열린 이슈 48개는 기존 번호 집합과 같고 신규 갱신은 없다.
- `master` 작업 트리는 깨끗하다. 전날 SQLP 글과 블로그 링크 개선은 운영 읽기 확인까지 완료됐으며 실제 성장 효과는 아직 측정 전이다. GROWTH-01 관측도 계속한다.
- 오늘은 1,000 DAU를 위한 측정 가능한 단계 계획을 기존 성장 계획에 추가하고, 검증된 검색 의도와 실제 연습 경로를 연결하는 원본 학습 글 한 편을 우선한다. 신규 문항 대량 제작·광고 변경·외부 발신·새 지출은 범위 밖이다. OPS-06의 잘못 연결된 조리 경로는 다중 경로·색인 영향이 커 별도 분기와 전용 검증이 필요하다.
- 담당: PO/Growth가 기준선·후보·측정 계획, Content가 원본 설명과 공식 출처, Engineering이 기존 글 구조에 게시와 로컬 검사, 독립 검수자가 검색 근거·문항 경로·기술 내용·최종 diff를 확인한다.
- 완료 기준: 검색어·페이지의 실제 관측 창과 대안을 기록하고, 로컬 fixture에서 시험명·문항·이동 경로를 확인한다. 공식 자료로 내용과 표현을 검수한다. 전체 `npm run check:local`과 독립 검수가 통과할 때만 `master` Git push 한 번으로 게시하고 영향 경로만 읽기 확인한다.
- 기대 지표: 새 글의 GSC 클릭, GA4 자연검색 랜딩, 대상 시험의 `practice_start`를 원천별로 28일 관찰한다. 최종 목표는 동일 GA4 속성의 DAU이며 글 하나의 인과 효과로 해석하지 않는다. 실패하거나 학습 이동을 방해하면 해당 글 등록과 구성 요소만 되돌린다.

## 진행 기록

- 오늘의 후보는 기존 3D 프린터 글과 겹치지 않는 학습 의도, 바리스타 2급 검색 의도, SQLD 추가 의도다. 잘못된 조리 시험 경로와 어제 게시한 SQLP 의도는 제외한다. 후보별 실제 연습 내용과 출처를 확인한 뒤 하나를 고른다.
- GSC 2026-08-09~11-08 Web 검색의 `바리스타 2급 필기 기출문제` 질의와 `/barista-2` 페이지에 실제 클릭·노출이 있다. GA4의 별도 랜딩 자료에도 해당 경로의 세션이 관측된다. 기간·분모가 다른 자료를 전환율로 결합하지 않는다. 3D 프린터는 레이어·서포트·인필 글이 이미 있고 SQLD에는 COUNT/NULL 글이 있어 오늘은 바리스타의 추출 비율·분쇄도 학습 의도를 선택했다.
- 로컬 fixture의 `/barista-2?verNbr=202611`을 열어 바리스타 2급 시험명, 2026-11 **연습문제** 회차, 에스프레소 분쇄도·흐름 저항 문항과 실제 선택지를 확인했다. 자체 제작 문항 세트에는 도징량·음료량 비율과 채널링도 있어 글과 학습 경로가 일치한다. 특정 발급기관의 기출문제라고 표시하지 않는다.
- (사)한국커피협회 공식 바리스타 2급 규정에서 커피 추출이 필기 범위에 포함됨을 확인했다. SCA 공식 교육 과정은 추출 변수 학습을, SCA의 에스프레소 조사 자료는 도징량 대비 음료 질량의 비율 정의와 1:2 사례를 설명한다. 기존 자체 제작 문항의 SCA 출처 URL은 현재 404여서 글에는 현재 열리는 공식 자료만 연결한다. 자격 발급기관마다 규정이 다를 수 있으므로 Quizeey 글을 어느 기관의 공식 기출·모의고사로 표현하지 않는다.
- 28일 평균 DAU를 2027-11-14까지 1,000명으로 높이는 관리 목표와 분기별 단계, 원천별 계측·품질 중단 조건을 성장 계획에 적었다. 현재 기준선과 수익·원천 식별자는 비공개 상태에만 둔다. 단계 숫자는 예측치가 아니다.
- 원본 바리스타 추출 비율·분쇄도 글을 기존 블로그 구조에 연결했다. 자체 확인 문제는 20 g 투입/50 g 음료의 1:2.5 계산과 오답 이유를 설명한다. 본문에서 추출 비율과 추출 수율을 구별하고 공식 기출이 아님을 밝힌다. 로컬 개발 서버에서 새 글 HTTP 200, 본문·출처·연습 CTA와 실제 11월 바리스타 문제 화면을 확인했다.
- 새 글의 무 JavaScript 이동·메타데이터·연습 경로와 모바일 밝은/어두운 테마 접근성을 기존 브라우저 회귀에 포함했다. 독립 콘텐츠 검토와 필수 `check:local`은 진행 중이다. 로컬 검사에서 DB/Auth fixture는 없어 전용 흐름 검사는 skip으로 보고한다.
- 독립 검수에서 계산, 오답 이유, 공식 링크 네 곳, 실제 바리스타 시험 ID·11월 문항 세트, 글의 접근성 구조와 공통 SEO 등록의 차단 결함은 발견되지 않았다. SCA 설문의 `1:2`를 빈도가 아니라 **평균 응답**으로 고치라는 의견을 반영했다. 별도 검토자는 로컬 화면과 GSC 원본 수치를 직접 재검증하지 않았으므로 해당 범위는 PO의 로컬 확인·원천 분석 영수증에 한정한다.
- 수정 후 최종 `npm run check:local` 종료 코드 0: 타입 검사, lint, 단위 184개, 빌드, 브라우저 108개, 광고 검사가 통과했다. 브라우저 13개는 격리 PostgreSQL/Auth fixture 부재로 skip이었다. 새 글의 모바일 두 테마 접근성과 무 JavaScript 연습 이동은 실제 실행에서 통과했다. 테스트가 다시 만든 기존 스크린샷은 출시 범위에서 제외한다.
