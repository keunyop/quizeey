# 2026-11-10 Quizeey PO 일지

## 시작 상태와 선택

- 공개 상태와 전날 일지를 재개했다. GSC 일별·AdSense 일별·GA4 학습 이벤트는 이미 비공개 기준선에 반영됐고 공개 운영 문서의 이전 release readback도 기록돼 있다. 이전 작업의 미커밋 일지·보고서·상태 변경은 보존한다.
- 로컬 입력함에 새 GA4 개요 보고서 6개가 있다. 기존 처리 manifest에는 이 파일들이 없다. 원천별 최신 집계 완료일과 학습 퍼널은 아직 확정되지 않았다.
- 담당: Data가 파일 구조·출처·기간·중복·차원·합계를 검증하고 PO가 사용 가능한 측정 범위를 결정한다. 이번 실행의 우선 작업은 새 보고서의 안전한 수집과 기준선 갱신이다.
- 완료 기준: 각 파일의 유효성 및 중복을 판정하고, 유효한 값만 ignored private baseline에 저장·재조회한 뒤 manifest를 전진한다. 불완전한 파일은 사유와 재요청 범위를 남긴다.
- 기대 지표: GA4 일별 사용자·유입·참여·재방문 중 확인 가능한 범위를 확정한다. 업로드 자체를 성과 개선으로 해석하지 않는다.
- release/복구: 원본과 수치는 비공개 경로에만 보관하고 공개 운영 기록에는 민감하지 않은 상태만 적는다. 제품 코드·운영 DB 변경은 예정하지 않는다. 검증 실패 시 기존 기준선과 manifest를 유지한다.

## 진행 기록

- 입력함의 새 GA4 개요 CSV 6개는 기존 처리 manifest에 없었다. 각 파일의 크기·SHA-256·원천 속성 표시·표별 포함 기간·열 너비·숫자 유효성을 검사했다. 원본 내용은 명령으로 실행하지 않았다.
- 90일 전체기간 표에서 신규 사용자·이벤트·조회 합계를 독립 표와 대조해 일치함을 확인했다. 주별 활동 사용자의 합은 기간 고유 사용자 수로 취급하지 않았다. 유입 채널별 세션과 source/medium 세션 합계, 국가·언어 행 합과 전체 고유 사용자에는 차이가 있어 합산 분모로 쓰지 않는다.
- `Nth day` 차트는 연속된 90개 인덱스이며 명시적 Date 열이 없다. 랜딩 표는 Google 자연검색 노출이며 GA4 랜딩 세션이 아니다. 동일한 열 이름을 가진 두 코호트 표는 단위가 달라 재방문율 계산에서 제외했다. GA4 광고 수익은 CSV에 통화가 없고 AdSense 확정수익과 다르므로 별도 원천으로 둔다.
- 검증된 전체기간 요약과 제한된 차트 계열만 ignored private baseline에 저장했다. 별도 readback에서 원본 6개 체크섬과 baseline·manifest 연결, 총 처리 9개를 확인했다. 원본 페이지명·검색어·수치·계정 정보는 공개 기록에 추가하지 않았다.
- 현재 운영 DB의 신고 상태를 읽기 집계로 재확인했고 open은 없다. GitHub 기존 미해결 이슈 48건도 모두 다시 조회했다. 사용자 원문과 ID를 새 공개 기록으로 복제하지 않았으며 조치·cursor 전진은 없다.
- 제품 코드·DB 쓰기·외부 메시지는 없다. 최신 원천 집계 완료일은 아직 확인되지 않아 완료된 28일 비교, 학습 실행별 완료율, 재방문 성과와 광고 개선 효과는 판단 보류다.
