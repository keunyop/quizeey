## 진행 기록

- 기본 로컬 shell은 sandbox 초기화 오류로 시작하지 못했다. 읽기 전용 명령의 샌드박스 밖 실행으로 이전 일지·보고서·공개/비공개 상태·접근·지표·백로그·보고서 정책을 확인했다. 시작 작업 트리는 깨끗하며 전날 운영 확인 문서 커밋에서 재개했다.
- 현재 DB 전체 열린 신고와 legacy GitHub 전체 열린 이슈 본문을 다시 확인했다. 새 항목 변화는 없고 전날 적용한 해설을 재실행하지 않았다. DB 조회는 잘못 추정한 스키마/상태 필드로 실패해 실제 metadata와 migration을 대조하고 올바른 쿼리로 성공했다. 이후에는 실제 스키마·열 계약을 먼저 사용한다. GitHub 수정 시각이 없어 기존 watermark는 유지한다.
- 업로드 보고서 전부를 manifest SHA-256과 대조했고 새 입력은 없었다. Google 수신·속성·최신 확정 범위가 미확인인 상태를 개선 효과로 바꾸지 않는다.
- 별도 Content 조사자가 한국 필터 GSC 원본의 실제 포함 기간 2026-08-09~11-08, 검색어·페이지 별도 근거와 Prusa 공식 기술 문서 네 개를 확인했다. 넓은 3D프린터운용기능사 필기 연습 수요를 근거로 첫 층·워핑 문제 해결 글을 선택한다. 첫 층 전용 검색어 수요는 미측정이다. SQLD/CCNA/위생 주제는 최근 글과의 반복을 피하기 위해 후순위로 두었다. 비공개 수치와 원본명은 공개하지 않는다.
- 개발 branch `content/20261120-printing-first-layer`에서 원본 사례·세 확인 문제·공식 출처와 기존 11월 연습 연결을 작성했다. 기존 층 수·서포트·인필 글과 목적을 구분한다. 첫 패치는 예상 원문 줄이 달라 적용되지 않았으며 적용 상태를 확인한 뒤 새 파일과 정확한 등록 줄로 나누어 적용했다.
- 격리 DB/Auth는 기존 설치 PostgreSQL 18에서 정상 기동했다. 처음 고른 workspace 내 PostgreSQL 17은 실행 파일의 한글 경로 처리로 초기화가 실패했고, 시스템 설치의 ASCII 경로로 복구했다. 앱은 PowerShell 스크립트 제한을 피하는 `npm.cmd run dev:local`로 시작했다. 통합 브라우저 도구가 실패해 동일한 로컬 경로를 Playwright로 검증한다.
- 실제 로컬 브라우저에서 정식 시험명·11월 20문항·첫 FDM 문항과 선택지를 확인했다. 새 글의 세 문제와 모든 오답 이유·네 공식 링크·기종/재료별 예외·중복 여부·등록/라우팅·검색 메타데이터와 회귀 소스는 별도 검수자가 검토했다. 기존 사이트맵의 최신 날짜 기대값과 해설 DOM selector를 전체 실행 전에 실제 계약과 맞췄다. 공개 검수 기록과 보고서도 별도 검토했다.
- 전체 로컬 검사에서 타입·lint·단위 190개·빌드는 통과했고 DB/Auth 포함 브라우저 회귀 143개가 진행 중이다. 실행 완료 전 결과를 합치거나 운영 성공으로 표시하지 않는다. 검증 중 생성되는 이미지와 타입 파일은 출시 파일에 넣지 않는다.
- 전날 적용 영수증과 현재 운영 문항을 대조해 수정 시각·본문 hash·해설·출처·보기 식별자/본문/정답이 모두 같음을 확인했다. 최초 비교는 이전 positional 배열과 현재 named 객체의 형식을 혼동했고, 한 임시 명령의 기본 인코딩도 실패했다. 저장 원문 형식을 직접 확인하고 명시적 UTF-8·같은 필드 계약으로 정규화해 대조를 통과했다. 운영 쓰기는 없다.
- 기존 보안 알림 확인을 위해 읽기 전용 npm audit를 시도했으나 장시간 응답이 없어 해당 작업 소유 프로세스만 중단했다. 감사 성공·취약점 0건으로 표시하지 않으며 기존 GitHub 알림 상세는 미확인으로 유지한다. 필수 check:local은 별도로 계속 진행한다.

- 최종 전체 `npm run check:local`이 종료 코드 0으로 완료됐다. 타입·lint·단위 190개·빌드·브라우저 143개·광고 시뮬레이션 6개 통과, 격리 DB/Auth 포함, skip 0이다. 실제 외부 광고 요청은 없다. 별도 검수된 다섯 파일의 SHA-256이 최종 검사 파일과 일치했다. 현재는 검증된 Git 출시 후보이며 운영 READY/readback 전까지 게시 성공으로 표시하지 않는다.
