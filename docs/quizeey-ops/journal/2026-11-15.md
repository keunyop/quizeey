# 2026-11-15 Quizeey PO 일지

## 시작 상태와 오늘 선택

- 전날 바리스타 글과 성장 계획은 비공개 배포 영수증에서 production READY와 영향 경로 읽기 확인이 완료됐다. 로컬 HEAD와 원격 master도 해당 커밋과 일치한다. 공개 상태의 release 후보 표기는 오늘 정합화한다.
- report 입력 원본은 처리 manifest의 체크섬·크기와 모두 일치한다. 새 업로드는 없고 GA4 합계 정합성·속성/확정일·학습 퍼널은 미확인 상태를 유지한다. 과거 대체 완료 입력 오류를 신규 장애로 세지 않는다.
- 오늘 최우선은 OPS-06이다. 양식·일식·중식·복어 경로에서 한식 문항이 표시되는 오인 학습을 차단하고 정확한 안내와 한식 경로를 제공한다. 여러 경로와 검색 색인에 영향을 주므로 `fix/ops-06-cooking-routes-20261115` 개발 브랜치에서 준비한다.
- 담당: Engineering은 경로·목록·색인 수정, Content는 검색 근거와 실제 연습 경로에 연결되는 오늘의 원본 글, 별도 reviewer는 원천·diff·검증 결과를 독립 확인한다. PO는 현재 신고함·상태·범위·최종 검증을 통합한다.
- OPS-06 완료 기준: 네 경로와 파생 경로의 잘못된 문제풀이 차단, 정확한 안내/대체 경로, 목록·검색·사이트맵/robots 정합성, 기존 한식 저장키·점수 보존, 정상 한식 흐름과 한국어/영어·모바일/테마 회귀 통과. 예상 성과는 시험 오인 학습 방지이며 이용자 성장 효과는 미측정이다.
- 일일 글은 기존 글과 의도가 겹치지 않는 검증된 검색 수요를 선택하고 실제 로컬 시험 문항과 공식 출처를 확인한다. 독립 콘텐츠 검수와 필수 로컬 검사 후 출시 가능 상태를 판정한다. 글의 검색·랜딩·학습 시작을 원천별로 28일 관찰한다.
- 검증은 로컬 fixture만 사용하고 필수 `npm run check:local`을 완료한다. DB/Auth fixture 미구성으로 생기는 skip은 명시한다. 운영 DB 변경·신고 해결·외부 발신·새 지출은 수행하지 않는다. OPS-06의 광범위 공개 변경은 구현·검증·검토 결과를 갖춘 뒤 승인 경계를 판단한다. 복구는 해당 경로 차단/색인 변경과 글 등록의 되돌리기이며 저장 기록은 변경하지 않는다.

## 진행 기록

- 일반 실행 도구의 초기화 오류가 발생했다. 승인된 읽기 전용 명령으로 지침과 상태를 확인했으며 애플리케이션 오류로 간주하지 않는다.
- legacy GitHub 열린 이슈 전체 조회에서 기존 번호 집합과 동일한 항목들을 확인했다. 원문·개인정보는 공개 운영 기록에 복제하지 않는다. 운영 DB 신고함 재조회는 진행 중이다.
- 운영 DB의 열린 문항/피드백 및 댓글 신고 전체를 재조회해 빈 목록을 확인했다. 과거 미해결 항목은 해결 상태와 일치하는 감사 기록이 있었으며 비공개 cursor의 오래된 미해결 표기를 정합화했다. GitHub 검색 도구는 수정 시각을 반환하지 않아 같은 번호 집합이라는 사실을 최근 본문 변경이 없다는 뜻으로 확대하지 않는다.
- OPS-06은 네 경로를 안내 페이지로 바꾸고 학습 데이터·저장 컴포넌트를 읽기 전에 반환하도록 구현했다. 목록·관련 링크·사이트맵에서 제외하고 `noindex`를 적용했다. 단위 검사 40개가 통과했다. 독립 검수에서 옛 문항/페이지 조건의 접근성을 지적해 명시적인 한식 조건 유지 링크를 추가했다.
- 실제 로컬 양식 경로에서 정확한 안내·한식 CTA와 문제 카드 부재를 확인했다. 격리 PostgreSQL 및 Auth HTTP fixture를 새로 시작해 이번 전체 브라우저 검사에 DB/Auth 흐름을 포함할 준비를 마쳤다. 운영 DB/Auth를 테스트 대상으로 사용하지 않는다.
- 오늘 글 후보는 실제 검색어·페이지 관측이 있는 미용사(메이크업) 위생 개념이다. 기존 원본 글과 의도가 다르고, 로컬 시험의 손 위생·도구관리·이상반응 문항을 확인했다. FDA/CDC 공식 본문과 대조하는 콘텐츠 검수를 진행한다.
- 독립 검수 완료: 조리 안내·목록 제외·한식 이동·기존 조건 유지 링크와 랜덤 세션의 저장 답안/북마크/점수/쿠키 복원을 로컬 브라우저에서 확인했다. 메이크업 글의 두 자체 문제 정답·오답 이유와 최소 20초 손씻기 문구를 FDA/CDC 공식 원문과 대조했고, 실제 공통 기초 세 문항으로 연결됨을 확인했다. 검색 원본 수치의 재분석은 콘텐츠 독립 검수 범위 밖이다.
