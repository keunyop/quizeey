## 진행 기록

- 기본 명령 실행은 sandbox 초기화 실패로 작동하지 않았다. 샌드박스 밖 읽기 경로로 이전 일지·보고서·공개/비공개 상태·접근·지표·백로그·스킬을 읽었다. 현재 작업 트리는 깨끗하고 전날 운영 확인 문서 커밋에서 재개한다.

- 현재 DB 전체 open 조회는 전날과 비교해 새로운 신고 변화가 없었다. 현재 문항 원문 hash·수정 시각·보기/정답·빈 해설/출처도 이전 검토와 일치했다. 운영 변경이나 신고 종결은 하지 않았다. 첫 조회는 스키마 이름을 잘못 지정해 실패했고 information_schema로 실제 스키마를 확인한 뒤 성공했다.
- legacy GitHub 열린 이슈 48개 전체 본문을 재확인했다. 번호 집합은 이전 기록과 같고 수정 시각이 제공되지 않아 watermark를 진전시키지 않는다. 모든 report 입력은 처리 manifest 해시와 같아 재처리하지 않았다.
- 여러 파일의 콘텐츠/언어 계약 변경을 검수하기 위해 개발 branch `feat/20261119-ccna-practice`에서 작업한다. 기존 영어 10월 23문항과 새 한국어 11월 5문항의 실제 로컬 시험명·첫 문항·보기를 각각 확인했다. 신규 문항은 별도 ID namespace를 사용하고 영어 UI에서는 해당 회차를 노출하지 않는다.
- 한국 필터 GSC의 넓은 CCNA 문제 검색 의도와 별도 CCNA 연습 페이지 근거를 다시 읽었다. 실제 차트 기간은 2026-08-09~11-08이며 마스크 불일치 전용 검색 수요나 동일 방문 전환은 미측정이다. 기존 계산 가이드 반복과 근거 없는 국가 확장은 제외하고 문제 해결 설명을 선택했다.
- 격리 PostgreSQL/Auth fixture를 정상 기동했다. 별도 검수자는 Cisco 공식 시험 범위와 다섯 주소 계산을 독립 확인하고, 첫 문항에 같은 IP 서브넷 조건을 명확히 쓰도록 권고했다. 원본 작성자와 검수자를 분리하며 실제 diff와 검증 결과를 최종 검수할 예정이다.

- 첫 전체 검사에서 단위 190개·빌드와 신규 5문항 채점/복원/API 검사는 통과했으나 신규 글의 JavaScript 비활성 검사 한 건이 실패했다. 실제 문제풀이 h1은 전체 한국어 시험명인데 새 테스트가 축약된 CCNA 200-301만 기대한 것이 원인이었다. 오류 문맥의 실제 제목과 사전 로컬 경로 확인이 일치했다. 검사를 중단하고 실패 로그를 보존했다. 실제 제목을 정확히 검증하도록 테스트만 수정하고 독립 검수 후 해당 흐름 및 전체 명령을 다시 실행한다. 실패 실행의 부분 성공을 최종 통과로 합치지 않는다.

- 수정된 글 브라우저 검사 2개를 로컬에서 재실행해 종료 코드 0으로 통과했다. JavaScript 비활성 읽기·정식 시험명·정확한 회차/문항/언어와 모바일 양 테마 접근성·답제출 범위는 보존했다. 별도 검수자가 오류 artifact·정식 제목 원천·변경된 테스트 해시를 대조해 승인했다. 전체 `npm run check:local`을 격리 DB/Auth 설정으로 처음부터 다시 시작했다.

- 최종 전체 `npm run check:local` 재실행이 종료 코드 0으로 완료됐다. 타입·lint·단위 190개·빌드·브라우저 141개·광고 시뮬레이션 6개 통과, 격리 DB/Auth 포함, skip 0이다. 광고 시뮬레이션의 실제 외부 요청은 없었다. 앞선 실패 실행과 부분 결과를 합치지 않았다.
- 출시 후보는 독립 검수한 CCNA 한국어 5문항·원본 문제 해결 글·기존 글 언어 안내/연결·필요한 회귀와 운영 기록이다. 공개 문서의 비공개 상세 집계를 제거하고 과거 초안 표현과 현재 상태를 구분했다. 생성된 이미지·광고 증거는 출시 파일에 포함하지 않는다. master Git push만 사용하며 READY/readback 실패 시 자동 재배포하지 않는다.
