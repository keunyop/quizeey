# 국가·시험 유입 다변화 계획

2026-11-10. 상세 수치·원천 파일·교차표는 ignored private 운영 보고서에 보관한다. 국가별 활동 사용자와 시험별 랜딩 세션은 다른 지표이며 현재 자료의 기간도 다르다. 국가×시험 유입은 교차 export 확보 전까지 미측정이다.

## 우선순위와 실행

| 순서 | 시장/시험 | 실행 | 확인할 근거 |
| --- | --- | --- | --- |
| 1 | 한국: SQLD·3D프린터·정보처리, 다음 CCNA·SQLP | 기존 안내와 문제를 홈 검색창 아래에서 발견하도록 연결. 다음 변경은 기존 페이지의 검색의도·학습 시작 경로를 확인해 한 요소만 개선 | 비조리 시험의 검색 클릭·랜딩 세션·학습 시작 절대량 |
| 2 | 미국: SAT/GED·ServSafe 및 AWS/Azure | 기존 영어 안내를 노출하고 국가×페이지 자료로 우선 시험 확정 | 국가 위치만으로 시험 수요·사용언어를 추정하지 않음 |
| 2 | 캐나다: Ontario G1·BC FOODSAFE 및 클라우드 | 기존 Ontario 표지판 안내 노출. 지역·교육제도 구분 유지 | 주별 관할과 공식 출처, 대상 경로 유입·학습 시작 |
| 3 | 인도·호주·영국 등: 클라우드·네트워크 | 국제 자격증 콘텐츠를 재사용할 후보. 실제 국가×페이지 검색 기회를 확인한 시험부터 개선 | 국가별 검색 노출·클릭·시작 및 검수·유지 비용 |
| 보류 | 일본·중국 현지 시험 | 공식 범위·언어 수요·검수자를 확인한 뒤 소규모 원본 파일럿 검토 | 접속 국가만으로 현지 시험 시장성을 주장하지 않음 |

국가명만 바꾼 페이지나 기존 글의 중복 발행은 하지 않는다. 새 문항은 공식 근거·설명·오답 이유·독립 검수·변경 이력이 필요하다. 외부 홍보 전송과 신규 지출은 별도 승인 범위를 유지한다.

## GROWTH-01: 기존 학습 경로 발견

- 문제/가설: 인기순 카드와 월별 목록 뒤에 있는 기존 안내를 홈 검색창 아래로 연결하면 더 다양한 학습 경로를 발견할 수 있다. 외부 검색 유입 증가나 인과효과는 아직 확인하지 않았다.
- 담당: PO/Data가 국가·시험 기준선, Growth가 우선순위·독립 검토, Engineering이 링크 구현·로컬 검증·복구를 맡는다.
- 범위: 한국어·영어 홈 각각 기존 목적지 링크 4개. 새 페이지·문항·DB 쓰기·추적 payload 추가 없음.
- 주지표: 대상 시험별 `practice_start` 이벤트 수. 유입 지표는 국가×시험 랜딩 세션. 현재 대상 시작·교차 기준선은 미측정이다.
- 보조지표: 해당 페이지 GSC 노출·클릭, 비조리 시험의 절대 세션, 유입이 관측된 시험 수. 조리시험 감소로 비중만 바뀐 것을 성공으로 보지 않는다.
- 평가: 운영 readback 다음날부터 28일을 이전 동일 길이·요일 구성과 비교. 비무작위 전후 관찰이며 시험 일정·계절성·추적 공백을 함께 기록한다. 일주일 후에는 결함만 점검한다.
- 판단 기준: 시험별 대상 랜딩 100세션과 학습 시작 30회에 미달하면 확대 판단을 보류한다. 이는 운영상 관측 기준이며 통계적 유의성을 뜻하지 않는다.
- 가드레일: 검색·문제풀이·모바일 가로넘침·키보드 접근·목적지 오류. 인기시험 절대 학습 시작의 악화도 확인한다. 탐색 방해/404가 확인되면 추가한 링크만 복구한다.
- 상태: 로컬 구현·목적지/모바일/키보드/독립 검토와 전체 `check:local` 통과. Git release readback 대기, 효과 미측정. 최신 상태는 [일지](journal/2026-11-10.md)와 [상태](state.json)를 우선한다.
