# 국가·시험 유입 다변화 계획

2026-11-10. 상세 수치·원천 파일·교차표는 ignored private 운영 보고서에 보관한다. 국가별 활동 사용자와 시험별 랜딩 세션은 다른 지표이며 자료의 기간도 다르다. 국가×시험×채널 export와 국가 필터 GSC 자료를 추가 검증했다. 전체 표시 세션과 차원 행 합계가 달라 교차표는 부분 기술 통계다. 최신 판단은 [추가 보고서](reports/2026-11-10-country-exam-followup.md)를 따른다.

## GROWTH-01: 기존 학습 경로 발견

- 문제/가설: 인기순 카드와 월별 목록 뒤에 있는 기존 안내를 홈 검색창 아래로 연결하면 더 다양한 학습 경로를 발견할 수 있다. 외부 검색 유입 증가나 인과효과는 아직 확인하지 않았다.
- 담당: PO/Data가 국가·시험 기준선, Growth가 우선순위·독립 검토, Engineering이 링크 구현·로컬 검증·복구를 맡는다.
- 범위: 한국어·영어 홈 각각 기존 목적지 링크 4개. 새 페이지·문항·DB 쓰기·추적 payload 추가 없음.
- 주지표: 대상 시험별 `practice_start` 이벤트 수. 유입 지표는 국가×시험 랜딩 세션. 현재 대상 시작·교차 기준선은 미측정이다.
- 보조지표: 해당 페이지 GSC 노출·클릭, 비조리 시험의 절대 세션, 유입이 관측된 시험 수. 조리시험 감소로 비중만 바뀐 것을 성공으로 보지 않는다.
- 평가: 운영 readback 다음날부터 28일을 이전 동일 길이·요일 구성과 비교. 비무작위 전후 관찰이며 시험 일정·계절성·추적 공백을 함께 기록한다. 일주일 후에는 결함만 점검한다.
- 판단 기준: 시험별 대상 랜딩 100세션과 학습 시작 30회에 미달하면 확대 판단을 보류한다. 이는 운영상 관측 기준이며 통계적 유의성을 뜻하지 않는다.
- 가드레일: 검색·문제풀이·모바일 가로넘침·키보드 접근·목적지 오류. 인기시험 절대 학습 시작의 악화도 확인한다. 탐색 방해/404가 확인되면 추가한 링크만 복구한다.
- 상태: 로컬 구현·목적지/모바일/키보드/독립 검토와 전체 `check:local` 통과. commit `f7718a6` production READY·한/영 홈 smoke 완료. 2026-11-11~2026-12-08 관측 예정, 효과 미측정. 최신 상태는 [일지](journal/2026-11-10.md)와 [상태](state.json)를 우선한다.
