# 국가·시험 유입 다변화 계획

2026-11-10. 상세 수치·원천 파일·교차표는 ignored private 운영 보고서에 보관한다. 국가별 활동 사용자와 시험별 랜딩 세션은 다른 지표이며 자료의 기간도 다르다. 국가×시험×채널 export와 국가 필터 GSC 자료를 추가 검증했다. 전체 표시 세션과 차원 행 합계가 달라 교차표는 부분 기술 통계다. 최신 판단은 [추가 보고서](reports/2026-11-10-country-exam-followup.md)를 따른다.

## 2026-11-12 사용자 증가 조사와 실행 순서

오늘 report 입력함의 신규 파일은 없고, 국가×시험 자료의 표시 총계와 행 합계 차이·원천 확정일·시험별 학습 시작은 여전히 확인되지 않았다. 아래는 기존 관측과 제품 경로를 바탕으로 한 **가설과 소규모 실행안**이다. 사용자 증가 효과나 국가별 시험 수요의 확정 결과는 아니다. 새 지출·외부 발신·새 시험 대량 제작은 포함하지 않는다.

소유자의 11월 12일 추가 요청에 따라 daily PO 실행마다 원본 블로그 글 한 편을 작성한다. 11월 12일 글은 한국 GSC의 한식조리기능사 필기 검색 의도, 실제 한식 ID 14 문제 세트, 식약처·Q-net 근거를 함께 확인해 [한식 식품위생 글](../../web/src/components/KoreanCookingArticle.tsx)로 선정했다. 양식조리 URL은 현재 한식 문제로 연결돼 별도 OPS-06으로 조사 중이므로, 양식 키워드의 큰 검색량만으로 글과 연습 경로를 약속하지 않는다. 게시 뒤 28일간 글의 GSC 클릭·자연검색 랜딩·해당 시험 학습 시작을 각 원천에서 관찰하고 신규/활동 사용자를 최종 결과로 보되, 동시 변경과 표본 부족이 있으면 인과효과를 주장하지 않는다.

11월 13일 글은 한국 GSC의 SQLP 기출·문제 검색 클릭과 실제 2026년 11월 SQLP 문제 세트를 확인해 [SQLP 실행계획 글](../../web/src/components/SqlpPlanArticle.tsx)로 선정했다. PostgreSQL 공식 문서의 계획 추정치·표현식 인덱스·다중 열 인덱스 원리를 자체 예시로 설명한다. 게시 뒤 28일간 새 글의 GSC 클릭·GA4 자연검색 랜딩과 SQLP 학습 시작을 원천별로 관찰한다. 현재 실행별 분모와 최근 export의 확정성이 부족하므로 전환율 또는 순증 효과는 주장하지 않는다.

11월 13일 추가 검토에서 해외 독자용 다음 글의 가장 구체적인 후보는 미국 대상 영어 Network+ N10-009의 ‘IP 주소로는 접속되지만 호스트 이름으로는 실패할 때: DNS와 DHCP의 첫 진단’이다. 미국 GSC의 N10-009 문제 검색어에는 노출이 있으나 관련 클릭은 확인되지 않았다. 별도 GA4 자료에는 미국 자연검색의 기존 영어 Network+ 연습 경로 랜딩이 있고, 로컬 fixture에서 실제 DNS·DHCP 문제와 시험명을 확인했다. 기존 영어 서브넷 글과 주제는 다르며 [CompTIA 시험 범위](https://www.comptia.org/en-us/certifications/network/)와 [DNS](https://www.rfc-editor.org/rfc/rfc1034), [DHCP](https://www.rfc-editor.org/rfc/rfc2131), [IPv4 link-local](https://www.rfc-editor.org/rfc/rfc3927) 원문으로 기술 내용을 검수할 수 있다. 그러나 국가별 클릭·학습 시작과 자료 확정성이 부족하고 오늘 원본 SQLP 글을 이미 게시했으므로 추가 글은 만들지 않았다. 11월 23일 같은 국가·경로의 검색어, 자연검색 랜딩과 실제 학습 시작을 다시 확인해 발행 여부를 결정한다. 블로그 문제풀이 링크는 한국어·영어 공통 버튼 표시로 개선해 기존 글의 학습 이동을 먼저 돕는다.

사용자 증가의 최종 관측은 같은 GA4 속성·완결 기간의 **신규 사용자와 활동 사용자**로 둔다. GSC 클릭은 검색 유입 신호, 랜딩 세션은 방문 신호, `practice_start`는 학습 품질 신호다. 이 수치를 서로 더하거나 같은 사용자로 연결하지 않는다. 현재 업로드 자료만으로는 해당 시험별 신규 사용자→학습 시작 전환율을 계산할 수 없다.

공통 가드레일은 답 정확성, 문제풀이 완료, 모바일·키보드 접근, 속도, 광고가 학습 동작을 가리지 않는지다. GROWTH-01은 2026-11-11~12-08 비무작위 관측이며, 다른 변경과 겹치면 그 사실을 기록하고 인과효과로 해석하지 않는다. 11월 23일에는 해외 후보의 근거를 재판단하고, 12월 8일 이후에 홈 링크 관측을 평가한다. 새 export가 없으면 효과 판단은 미측정 또는 보류다.

## GROWTH-01: 기존 학습 경로 발견

- 문제/가설: 인기순 카드와 월별 목록 뒤에 있는 기존 안내를 홈 검색창 아래로 연결하면 더 다양한 학습 경로를 발견할 수 있다. 외부 검색 유입 증가나 인과효과는 아직 확인하지 않았다.
- 담당: PO/Data가 국가·시험 기준선, Growth가 우선순위·독립 검토, Engineering이 링크 구현·로컬 검증·복구를 맡는다.
