# 2026-11-13 Quizeey PO 보고 — SQLP 학습 글과 문항 신고 검토

## 핵심 요약

신규 문항 신고는 소유자 승인과 추가 독립 검토를 거쳐, 기존 정답 ④를 유지하면서 비어 있던 해설·출처를 운영 DB에 보완하고 재조회했다. 공유된 근거를 반영해 문항의 해석상 한계도 명시했으며 신고는 열린 상태로 유지한다. 오늘의 원본 SQLP 실행계획 글은 운영 게시·읽기 확인을 마쳤다. 추가로 한국어·영어 블로그의 문제풀이 링크를 버튼으로 개선해 전체 로컬 검증과 운영 게시·영향 경로 읽기 확인을 마쳤다.

## 완료

- 로컬 report inbox의 기존 15개 파일을 처리 manifest의 체크섬과 대조했다. 새 원본은 없었다. 기존 GA4 총계 불일치 3건과 manifest 처리 실패 2건은 미해결이다. 신규 DB 문항 신고 한 건을 확인했고, 기존 GitHub open issue ID 집합에서는 새 ID를 찾지 못했다. 공개 기록에는 신고 원문·식별자와 비공개 지표를 옮기지 않았다.
- 새 신고의 문항·선택지·정답·저장 점수 영향을 확인했다. 별도 검토자가 동일 선택지와 정답 ④가 표시된 [독립 기출 보관본](https://cbtbank.kr/exam/ja20140126)을 직접 확인했다. [Yale Teachers Institute](https://teachersinstitute.yale.edu/curriculum/units/2009/3/09.03.11/13)는 얼음·소금 혼합물의 빙점 강하를, [Alabama Cooperative Extension](https://www.aces.edu/blog/topics/food-safety/grilling-alabama-seafood/)은 석쇠 부착을 줄이기 위한 예열·기름칠을 설명한다. 기존 문항의 ‘빙점 강화’는 부정확한 옛 표현이므로 해설에서 뜻을 밝혀야 한다. 정답 변경은 권하지 않는다.
- OPS-06 원천 자료를 대조했다. 양식·일식·중식·복어 URL 네 개가 한식 시험 ID와 문제·학습 기록을 공유한다. 이 네 시험의 별도 검수 문항과 ID는 확인되지 않았고 파생 페이지까지 36개 URL이 영향을 받는다. 정확한 안내 페이지, 문제풀이·목록·색인 정리, 기존 한식 기록 보존을 포함한 별도 교정 범위를 backlog에 기록했다.
- 국내 SQLP 기출·문제 검색에서 기존 학습 페이지로 유입되는 근거를 바탕으로 원본 실행계획 글을 만들었다. 전체 행 조회, `lower(email)` 검색, 다중 열 인덱스의 앞 열 조건을 예시로 설명한다. PostgreSQL 공식 문서와 DataQ 종목 안내를 확인했고, 실제 2026년 11월 SQLP 문제 세트로 연결한다. 독립 콘텐츠 검토에서 지적된 `EXPLAIN` 추정치와 `EXPLAIN ANALYZE` 실제 실행의 차이를 수정했다.
- 공유된 [생선 조리 원문](https://www.nongmin.com/article/20000927205571)은 소금 전처리가 생선의 수분을 빼고 살을 단단하게 하는 과정과 석쇠에 기름·식초를 바르는 직접 부착 방지 과정을 구분한다. 기존 해설 초안의 단정적 표현을 폐기했다. 원문·선택지·정답·시험을 모두 확인하는 조건부 SQL을 격리 fixture의 정상/불일치 사례로 검증하고 운영에 한 번 적용했다. 운영 재조회에서 새 해설·클릭 가능한 세 출처·기존 정답 ④를 확인했다. 문항의 표현상 모호성은 남아 있어 신고는 열린 상태다.
- 블로그 전체의 문제풀이 링크를 공통 버튼 스타일로 개선했다. 기존 링크 의미와 클릭 기록은 보존한다. 별도 검토자가 한국어·영어 글 8개에 적용되는지 읽기 전용으로 확인했다. 미국 영어 Network+ N10-009의 DNS·DHCP 첫 진단 글을 해외 후보로 검토했지만, 관련 미국 검색어는 노출만 확인되고 국가별 학습 시작 근거가 부족해 오늘 두 번째 글은 게시하지 않았다.

## 검증·출시 기록

- 전체 로컬 검증: PostgreSQL/Auth 격리 fixture를 포함한 `web`의 `npm run check:local` 종료 코드 0. TypeScript, lint, 단위 183개, 빌드, 브라우저 116개, 광고 검증 모두 통과했다. DB/Auth 브라우저 검사는 건너뛰지 않았다. 처음 실행에서 기존 150문항 테스트의 시간 제한과 인기순 테스트의 누적 조회 수 가정이 실패해 두 검사를 안정화했고, 새 fixture에서 전체 명령을 다시 실행해 통과했다. fixture 및 브라우저 서버 종료를 확인했다. 이 fixture 결과는 운영 DB/Auth 흐름의 검증으로 해석하지 않는다.
- 버튼 변경 후 전체 로컬 검증을 새 격리 PostgreSQL/Auth fixture로 다시 실행했다. 종료 코드 0; TypeScript, lint, 단위 183개, 빌드, 브라우저 117개, 광고 검사 통과. 새 한국어·영어 모바일 버튼·밝은/어두운 테마 검사가 포함됐다. DB/Auth 검사는 건너뛰지 않았고 fixture·브라우저 서버를 종료했다. 운영 DB 해설은 별도 조건부 SQL과 운영 행 재조회로 확인했다.
- 제품 게시: 커밋 `6201e126a1c5dbbd2f4f158deaace91ebcc81f52`를 `master`에 한 번 push했다. 원격 브랜치의 SHA가 일치한다. Vercel 운영 Git 배포 `dpl_EgzttCcg7LFDAi3hZBsPsrThhp4M`이 같은 SHA로 READY이며 `quizeey.com` 별칭을 가진다. 별도 CLI/API 배포는 하지 않았다.
- 운영 확인: 새 글, 블로그 목록, 실제 2026년 11월 SQLP 연습 경로에 대해 읽기 전용 GET 세 건만 실행했다. 모두 HTTP 200이고 예상 글·링크·문항 표지를 포함한다. 운영 전체 회귀나 크롤링은 실행하지 않았다.
- 버튼 개선 출시: 검증 커밋 `4d52dea8a586de6fff44fafc1e7e6d19d7626729`를 `master`에 한 번 push했고 원격 SHA가 일치했다. Vercel 운영 Git 배포 `dpl_5PhRfqNyB9fBjbaRAzcM1tgfXku9`는 같은 SHA로 READY이며 운영 도메인 별칭을 가진다. 한국어 SQLP 글과 영어 Network+ 글 두 경로만 읽기 GET으로 확인해 HTTP 200과 예상 문제 이동 링크를 확인했다. 운영 전체 회귀·크롤링·별도 CLI 배포는 하지 않았다.

## 성과

오늘 확인된 것은 글 작성·경로 연결·문항 설명 보완과 블로그 버튼 게시다. 검색 유입 증가, 학습 시작 증가, 신규 사용자 획득은 아직 측정되지 않았다. 게시 후 28일 동안 SQLP 글과 기존 영어 글의 GSC 클릭, 연결된 GA4 유입 및 각 시험 학습 시작을 원천별로 관찰한다. 기존 GA4 집계 차이와 실행별 분모 공백 때문에 전환율이나 증분 효과를 단정하지 않는다.

## 후속 결과: 소유자 지정 정답 ③ (위의 정답 ④ 유지 기록보다 최신)

소유자의 추가 지시에 따라 해당 문항은 운영에서 세 번째 보기를 유일한 정답으로 채점한다. [Yale Teachers Institute](https://teachersinstitute.yale.edu/curriculum/units/2009/3/09.03.11/13)의 설명처럼 얼음에 넣은 소금은 어는점을 낮춘다. 따라서 ‘빙점 강화’라는 보기 표현을 문자 그대로 판단했다. 다만 [2014년 기출 보관본](https://cbtbank.kr/exam/ja20140126)은 ④를 정답으로 표시하고, [농민신문의 생선 조리 자료](https://www.nongmin.com/article/20000927205571)는 생선 소금 전처리와 석쇠 예열·기름/식초 처리를 구별한다. 새 해설에 이 차이와 해석 여지를 명시했다. 역사적 공식 정답이 ③이었다고 주장하지 않는다.

기존 브라우저 저장 답안은 선택지를 보존하고 현재 정답으로 화면 점수·오답 복습을 다시 계산한다. 브라우저 저장값은 다음 저장 동작 때 갱신되며 과거 집계치는 소급 수정하지 않았다. 독립 코드·문항·SQL 검수를 마쳤고, 과거 ④ 선택의 정답→오답과 ③ 선택의 오답→정답을 단위 검사로 확인했다. 격리 PostgreSQL에서는 변경 대상과 불일치 차단 사례가 통과했다. `npm run check:local`은 격리 PostgreSQL/Auth fixture 포함 종료 코드 0으로 타입·린트·단위 184개·빌드·브라우저 117개·광고 검사를 통과했다. DB/Auth 검사는 건너뛰지 않았다.

검증 커밋 `946badfd7a6ae871f700ee2bf803ee9beb25dab2`를 `master`에 한 번 push했고 원격 SHA가 일치했다. 같은 SHA의 Vercel Git 운영 배포 `dpl_CVmoG2coTBYPQESnCRvpC7hSzVBk`가 READY이며 운영 도메인 별칭을 가진다. 그 후 조건부 운영 DB 변경을 한 번 적용했다. 운영 행 재조회에서 정답 플래그 `[false,false,true,false]`, 새 해설, 기존 출처 보존을 확인했다. 실제 문항 경로는 읽기 전용 새로고침에서 기대한 시험·문항·보기 4개를 표시했다. 정답 제출이나 운영 전체 회귀는 실행하지 않았다.

신고는 문항 표현의 모호성과 역사적 정답표 차이 때문에 열린 상태다. 현재 채점 반영은 완료했으나 장기적으로 보기 표현을 개정할지, 과거 채점 데이터를 어떻게 안내할지 결정해야 한다. 변경으로 인한 학습 성과·유입 효과는 아직 측정되지 않았다.
