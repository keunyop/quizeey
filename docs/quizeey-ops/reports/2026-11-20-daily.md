# 2026-11-20 Quizeey PO 보고

오늘은 3D프린터 첫 층 부착 실패와 모서리 들뜸을 구분하는 원본 학습 글을 작성했다. 실제 11월 연습 경로의 시험명·20문항·첫 FDM 문항을 로컬에서 확인했고, 별도 검수자가 공식 원문과 세 확인 문제의 정답·오답 이유를 검토했다. 최종 전체 로컬 검사 후 같은 SHA의 Git production READY·도메인 연결·영향 경로 세 곳 읽기 확인을 마쳤다. 학습·검색 효과는 미측정이다.

## 완료한 작업과 근거

- 현재 DB 전체 열린 신고와 legacy GitHub 전체 열린 이슈 본문을 다시 확인했다. 새로운 항목 변화가 없고, 전날 반영한 해설·공식 출처의 현재 revision과 정답·보기 상태도 유지됐다. 기존 SQL을 재실행하거나 신고를 종결하지 않았다.
- 업로드 보고서의 SHA-256을 처리 manifest와 대조했고 새 입력이 없었다. GA4 속성·test_id 수신·원천 확정일의 공백을 유지하며 없는 값을 0이나 성장으로 바꾸지 않는다.
- 한국 필터 GSC 원본의 실제 기간 2026-08-09~11-08에서 넓은 3D프린터 필기 연습 의도와 별도 연습 페이지 근거를 확인했다. 첫 층·워핑 전용 검색어 수요나 동일 방문 전환은 미측정이다. 최근 SQLD·CCNA·위생 글 반복보다 기존 3D 학습의 다른 문제를 선택했다.
- [새 글](../../../web/src/components/PrintingFirstLayerArticle.tsx)은 출력 실패 시점, 노즐 간격, 열수축·재료별 냉각, 스커트·브림·서포트 역할을 두 사례와 세 원본 확인 문제로 설명한다. 범용 온도·Z 숫자나 한 가지 원인 확진을 제시하지 않는다. Prusa 공식 기술 자료를 연결하고 기종·표면·재료별 차이를 명시했다.
- [검수 기록](../../seo/printing-first-layer-review-20261120.md)에 작성자와 별도 검수자, revision, 영역·난이도·정답 집합·오답 이유·공식 출처·중복 확인을 보존했다. 블로그 안 세 문제이며 기존 연습 DB·정답·점수는 변경하지 않는다.

## 검증과 출시

실제 로컬 fixture에서 3D프린터운용기능사 2026-11 원본 20문항과 첫 문항·선택지를 확인했다. JavaScript 비활성 글 읽기와 해설, 정확한 연습 경로, 모바일 양 테마 접근성·가로 넘침, 답 제출과 해설까지 검증하는 브라우저 회귀를 추가했다. 기존 사이트맵의 최신 날짜 기대값도 새 글 날짜로 갱신했다.

독립 콘텐츠·코드 검수는 미해결 finding 없이 완료했고 최종 검수 파일 다섯 개의 SHA-256도 일치했다. 전체 `npm run check:local`은 종료 코드 0으로 완료됐다. 타입·lint·단위 190개·빌드·브라우저 143개·광고 시뮬레이션 6개 통과, 격리 PostgreSQL/Auth 포함, skip 0이다. 실제 외부 광고 요청은 없었다. 로컬 fixture 결과이며 운영 DB/Auth 설정 전체 검증을 뜻하지 않는다. 커밋 `3f1831a`를 상시 승인 범위에서 master Git push 한 번으로 반영했다. 원격 SHA와 production READY 배포 SHA·도메인 연결이 일치하고 새 글·목록·11월 연습 경로 세 GET 모두 HTTP 200과 예상 내용을 확인했다. 전체 기록은 [오늘 일지](../journal/2026-11-20.md)를 따른다.

복구 범위는 새 글·등록·연결의 Git revert다. 상시 승인 범위의 검증된 작은 콘텐츠만 master Git push 한 번으로 반영하며 필수 검사가 실패하거나 생략되면 출시하지 않는다. 프리뷰 배포·호스팅 회귀·운영 DB 쓰기·신고 조치·외부 답신은 범위에 없다.

## 성과와 다음 순서

11월 20일 운영 확인을 마쳤으므로 11월 21일~12월 18일 완결 28일 동안 GSC 글/검색어와 GA4 해당 시험 학습 시작을 별도로 관측한다. 속성·시험 차원 수신·최신 집계 확정 전 전환율이나 개선 효과를 추정하지 않는다.

다음 후보는 OPS-02 비공개 보관·현재 파일 정리 범위 결정, GA4 시험별 수신과 확정 범위 확인, 이미 게시한 CCNA·SQLD·조리 글의 관측이다. 기존 보안 알림 확인용 읽기 전용 의존성 감사는 응답 없이 중단되어 상세 확인을 마치지 못했다. 필수 로컬 검사 통과와 구분하며 취약점이 없다는 결론을 내리지 않는다. 원본 수치·신고 식별자·상세 영수증은 비공개 기록에만 보관한다.

최종 운영 확인 문서는 로컬 문서 커밋에 보존하고 다음 검증된 정기 출시에 포함한다. 기록만을 위한 두 번째 push·배포는 하지 않는다. 작업 소유 로컬 앱/DB/Auth 서버는 종료했다.
