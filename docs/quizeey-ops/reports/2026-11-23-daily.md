# 2026-11-23 Quizeey PO 보고

한식조리 가식부 수율·구입량 역산을 설명하는 [원본 학습 글](../../../web/src/components/CookingYieldArticle.tsx)과 세 확인 문제를 작성했다. 전체 로컬 회귀에서 발견한 조기 답안 선택 유실도 원인 재현 후 수정했다. 최종 전체 검사와 독립 검수를 통과해 Git 출시를 준비한다. 운영 게시 완료 전까지 출시 성공으로 표시하지 않는다. 최종 결과는 [오늘 일지](../journal/2026-11-23.md)에 이어 쓴다.

## 완료와 근거

- 현재 DB 전체 열린 신고와 legacy GitHub 전체 열린 이슈 원문은 전날과 같다. 이전 보강 문항의 revision·본문·해설·출처·보기·정답도 적용 영수증과 일치한다. 운영 DB 변경·신고 종결은 없다.
- 보고서 입력 체크섬은 모두 처리 manifest와 일치해 중복 처리하지 않았다. 원천 총계/행 합계·속성·시험별 수신·집계 확정의 기존 공백을 유지한다. 최근 production의 1시간 error/fatal 집계에는 반환된 그룹이 없었으며 그 범위 이상의 무장애를 주장하지 않는다.
- 한국 필터 GSC의 실제 2026-08-09~11-08 필기 연습 의도와 별도 한식 페이지를 근거로 삼고 국가 필터 없는 후속 자료와 구분했다. 최근 SQLD·바리스타·3D·CCNA 및 기존 한식 위생/감염 글과 비교해 손질 후 가식부·수율/손실률·구입량 계산을 선택했다. 수율 전용 검색 수요와 동일 방문의 전환은 미측정이다.
- USDA Food Buying Guide 원본 PDF의 AP/EP 정의·Method 3 역산·수율 변동 요인을 작성자와 다른 검수자가 직접 읽었다. [문항 검수 기록](../../seo/cooking-yield-review-20261123.md)에 정답 3/1/2·여섯 오답·가정률·손질 단계·검수 역할을 연결했다.

## 검증과 출시

로컬 한식조리 11월 경로에서 실제 시험명·첫 수율 문제·선택지·75% 정답 제출·계산 해설을 확인했다. 회차 전체80/기본 화면20 경계를 글에 명시한다. 새 글의 세 문항은 글 안 확인 문제이며 기존 문항·점수 변경은 없다.

첫 전체 검사는 기존 한국 블로그 사이트맵의 전날 날짜 기대값으로 단위 검사 1건이 실패했다. 실패 로그·종료 영수증을 보존하고 오늘 날짜로 정상 갱신한 뒤 독립 검토·전체 재실행 대상으로 삼았다. 실패 실행을 최종 통과로 세지 않았다. 격리 DB/Auth 포함 전체 검사·JS 없는 읽기·모바일 양 테마·접근성·실제 연습 연결의 최종 영수증을 확인하기 전 출시는 차단했다.

다음 두 실행은 기존 320문항 검사에서 5초 경계를 넘겨 실패했다. 다른 빌드 종료 후에도 재현되어 그 빌드만을 원인으로 단정하지 않았다. 같은 기본 시간 제한·문항·검사를 단독 실행했을 때 3/3 통과, 320문항 본체 약 1.018초를 확인했다. 전체 suite 간 경합을 줄이도록 로컬 단위 검사를 한 worker로 직렬화했고 별도 검수자가 원본 진단·변경을 확인했다. 시간 제한·assertion·DB/Auth·브라우저 범위는 유지했다.

직렬화 후 단위 190개·빌드는 통과했으나 브라우저 148통과/1실패로 전체 실행은 실패했다. 원본 추적과 별도 정상/JS 지연 재현으로, 준비 전 보기 선택은 화면의 체크만 바꾸고 앱 상태에 반영되지 않는 문제를 확인했다. [입력 준비 가드](../../../web/src/components/Practice.tsx)와 한국어/영어 두 지연 회귀를 추가했다. 초안의 fieldset 비활성 matcher 오류는 설치 소스와 대조해 실제 자식 input 검사로 교정했으며 그 초기 실패를 앱 원인 증거로 세지 않는다. 별도 검수자는 서버/최초 클라이언트 일치·준비 후 기존 선택/키보드/채점/저장 로직 보존과 회귀 교정을 검토했다. 수정 후 집중 검사와 전체 필수 검사의 최종 성공 전 출시는 차단했다.

## 관측과 다음 순서

최종 코드의 전체 `npm run check:local`은 종료0으로 타입·lint·단위190·빌드·브라우저151·모의 광고6이 한 회차에서 모두 통과했다. 격리 DB/Auth 포함, 테스트 생략0, 실제 외부 광고 요청0이다. fixture 빌드의 운영 자격증명 preflight 생략은 테스트 생략과 구분한다. 생성된 기존 공개 화면/광고 산출물 변경은 제외했고 최종 아홉 파일 해시와 실제 로그를 독립 검수자가 대조해 승인했다. 이전 실패 네 실행과 집중 검사를 합산한 결과가 아니다.

운영 확인 다음 날부터 완결28일 GSC 글/검색어와 GA4 한식 학습 시작을 별도 관측한다. 속성·시험별 수신·시간대·확정 범위 전에는 효과·전환율을 추정하지 않는다.

기존 GitHub 보안 알림 API는 connector의 허용 endpoint 밖이어서 상태 확인이 제한됐다. 전날의 검증된 패치 반영과 알림 종결은 구분한다. OPS-02 비공개 보관/현재 트리 정리 범위, GA4 수신/확정 공백, 기존 글의 완결 관측을 다음 큐로 유지한다. 신고 종결·외부 답신·새 비용·파괴적 정리는 별도 승인 경계다.
