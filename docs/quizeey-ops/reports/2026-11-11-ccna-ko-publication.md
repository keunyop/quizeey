# CCNA IPv4 서브네팅 한국어 글 게시

## 결정과 범위

소유자가 11월 16일 목표보다 앞서 검수된 한국어 초안을 게시해 달라고 요청했다. 기존 초안의 계산과 Cisco 공식 근거를 블로그 글로 옮기고, 한국어 블로그 목록·사이트맵·CCNA 시험 페이지에서 찾을 수 있도록 연결했다. 새 연습문항 5개는 아직 작성·검수되지 않아 게시 글에서 예고하지 않았다. 연습 링크는 기존 2026-10 영어 자체 제작 회차로 연결하며, 주제별 필터가 없다는 점을 밝혔다.

## 검수와 검증

- 독립 검수자가 `/26`, `/23`, `/28`의 주소 계산, 게이트웨이 판정, Cisco v1.1/v2.0 범위와 전환일을 원문과 대조했다. 검수 중 연습 링크가 처음부터 23문항 전체를 보여주는 것처럼 읽히는 표현을 찾아 실제 동작에 맞게 고쳤다.
- 제품 통합: `/blog/ccna-ipv4-subnetting-gateway`, `/blog`, `/ccna-200-301`, `/sitemap.xml`. 한국어 글만 해당 언어 경로에서 제공한다.
- 로컬 필수 검사: 최종 `npm run check:local` 종료 코드 0. 타입 검사·lint·단위 테스트 183개·빌드·브라우저 테스트 99개·광고 회귀가 통과했다. 브라우저 13개는 DB/Auth fixture 부재로 skip되어 해당 흐름은 이번 검사로 검증되지 않았다.
- 게시 결과: `master` Git push 한 번으로 커밋 `5506e01`이 production READY가 되었고 `quizeey.com` 별칭을 확인했다. 새 글·블로그 목록·CCNA 시험 페이지 세 경로에서 HTTP 200과 본문·발견 링크를 읽었다. 게시만으로 검색 유입이나 학습 시작 증가를 주장하지 않는다.

## 다음 순서

기존 2026-10 세트의 해당 문제를 학습 경로로 사용한다. 별도 원본 5문항은 답·해설·오답 이유·공식 출처를 작성해 독립 검수한 후 게시 여부를 결정한다. 기존 미해결 신고와 OPS-01/OPS-02 승인 경계는 유지한다.
