# 2026-11-10 국가·시험 유입 추가 PO 보고서

Owner가 추가한 GA4 국가×랜딩×채널 자료와 한국·미국·캐나다 국가 필터 GSC 자료를 검증해 비공개 상세 보고서와 기준선에 반영했다. 원본·개별 수치·사용자 대화·식별자는 공개 저장소에 기록하지 않는다.

## 확인된 방향

- 한국은 조리시험 랜딩이 강하지만 SQLD·3D프린터·SQLP·CCNA에서도 실제 랜딩 세션과 검색 클릭이 관측됐다. 기존 SQLD·3D 글을 반복하기보다 CCNA 학습 경로를 다음 신규 콘텐츠로 정했다.
- 미국과 캐나다는 전체 방문만으로 영어 시험 검색 수요를 판단할 수 없다. 국가 필터 검색 클릭과 시험별 Organic Search가 아직 적어 기존 영어 경로의 색인·검색의도·학습 시작을 먼저 확인한다.
- 일본·호주에서는 CCNA 경로의 소규모 Organic Search 세션이 관측됐다. 현재 한국어 경로이며 검색어·사용 언어는 미확인이다. 다음 해외 검토에 포함하되 현지어 시험 수요로 단정하지 않는다.
- GA4의 표시 총계와 차원 행 합계가 일치하지 않는다. 국가·시험 표는 부분 기술 통계로만 사용한다. GSC 전체 클릭과 Pages/Queries 표도 합계가 다르다. 두 자료의 기간·지표가 달라 합산하거나 성장 실험의 효과로 해석하지 않는다.
