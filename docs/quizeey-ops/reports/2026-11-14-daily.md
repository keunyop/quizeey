# 2026-11-14 Quizeey PO 보고 — 1,000 DAU 계획과 바리스타 학습 글

## 핵심 요약

일간 활동 사용자 1,000명 목표를 단일 최고일이 아닌 **완결 28일의 평균 1,000명**으로 정의하고 2027년 11월까지의 단계 목표와 측정·품질 조건을 [성장 계획](../growth-plan.md)에 기록했다. 기존 검색 수요와 실제 연습문제가 연결되는 바리스타 2급 추출 개념을 오늘의 원본 글로 선택했다. 현재 수치의 속성·시간대·확정일은 미검증이므로 기준선은 비공개 잠정치이고 성장 성과는 아직 없다.

## 완료

- 기존 report inbox 15개 원본을 처리 manifest의 체크섬과 대조해 새 업로드가 없음을 확인했다. 현재 DB에 열린 문항·댓글 신고는 없었다. 이전 문항 신고는 이 실행 전에 관리자 해결 감사 기록이 남았고, 역사적 정답과 현행 표현의 모호성은 별도 검토 대상으로 유지했다. legacy GitHub 열린 이슈 48개의 번호 집합은 기존과 같다. 개인정보·신고 원문·원천 ID를 공개 기록에 옮기지 않았다.
- 동일 GA4 속성의 Vancouver 날짜별 `Active users`를 North Star로 정했다. 2027-02/05/08/11의 관리 목표를 각각 150/300/600/1,000 DAU로 두고, OPS-06 학습 경로 교정→검증된 검색 의도의 연습 연결→재학습 개선→계측 정비 순서를 결정했다. 단계 수치는 예측치가 아니다.
- GSC Web 검색의 2026-08-09~11-08 관측에서 바리스타 2급 필기 검색어와 `/barista-2` 페이지의 클릭·노출을 확인했다. 3D 프린터와 SQLD에는 겹치는 글이 있고 SQLP 글은 전날 게시됐다. 잘못된 조리 시험 경로는 콘텐츠 확장 후보에서 제외했다.
- 로컬 fixture에서 2026년 11월 바리스타 2급 연습 회차의 실제 문제와 시험 ID를 확인한 뒤, 투입량 대비 음료 질량의 비율·분쇄도·채널링을 설명하는 원본 글과 자체 확인 문제를 작성했다. 계산, 오답 이유, 공식 출처 네 곳과 실제 연습 링크를 포함한다. 기관별 자격을 구분하고 공식 기출문제가 아니라고 명시했다.
- 별도 검토자가 계산·오답·실제 문항 세트·공식 출처·접근성 구조를 대조했다. SCA 설문의 `1:2` 표현을 원문에 맞춰 **평균**으로 정정했다. 새 글의 JavaScript 비활성 이동과 모바일 두 테마 접근성을 브라우저 회귀에 추가했다.

## 검증·출시 기록

- 로컬 개발 서버에서 글과 실제 바리스타 연습 경로 HTTP 200 및 본문·출처·문항 표시를 확인했다. 독립 검토 의견 반영 후 전체 `npm run check:local` 종료 코드 0: 타입 검사, lint, 단위 184개, 빌드, 브라우저 108개, 광고 검사가 통과했다. 새 글의 모바일 밝은/어두운 테마 접근성·JavaScript 비활성 이동 검사가 포함됐다. 격리 PostgreSQL/Auth fixture가 없어 해당 전용 브라우저 13개는 건너뛰었으며, 정적 글 검사를 운영 DB/Auth 검증으로 해석하지 않는다.
- 위 검증 결과로 `master` Git release 후보를 확정했다. 배포 SHA·READY·운영 읽기 확인은 push 이후 비공개 release 영수증에서 기록하며, 이 커밋 단계의 문서는 운영 반영을 미리 주장하지 않는다.

## 성과

측정된 신규 사용자·검색 클릭·학습 시작 증가는 아직 없다. 게시 후 첫 완결일부터 최소 28일 동안 새 글의 GSC 클릭, GA4 자연검색 랜딩, 바리스타 학습 시작을 원천별로 관찰한다. 검색어 클릭을 개별 사용자나 학습 전환으로 환산하지 않는다.

## 진행 중·대기

- OPS-06 네 조리 시험 URL은 실제로 한식 문항과 기록을 공유하므로 별도 분기에서 안내·목록·색인을 함께 고쳐야 한다. 영향을 받는 파생 URL과 기록 보존 검증이 필요하다.
- GA4 표시 총계와 차원 행 합계의 차이, 속성 시간대·최신일 확정, `test_id` 기반 실행별 학습 시작·완료 및 재학습 코호트는 미해결이다. 신규 지출이나 광고 변경은 하지 않았다.
- 현행 문항의 정답 변경과 이전 공식 정답 사이에 남은 모호성은 콘텐츠·채점 정책 검토가 필요하다. 신고의 해결 상태만으로 단일정답성 문제가 해결됐다고 보지 않는다.
