# 2026-11-16 Quizeey PO 보고 — SQLD 학습 경로

## 핵심 요약
기존 SQLD 가이드에서 11월 원본 연습문제로 바로 가는 길을 앞당기고, `WHERE`와 `HAVING`을 구분하는 오늘의 원본 학습 글을 준비했다. 실제 SQLD 시험 화면과 20문항을 로컬 fixture에서 확인하고, PostgreSQL 공식 근거·계산·오답 이유·링크를 별도 검토했다. 전체 로컬 검증은 통과했으며 운영 반영은 배포 읽기 확인 전이다.

## 완료
- Owner report 입력함에는 처리 목록에 없는 새 파일이 없다. 운영 DB의 문항·피드백 및 댓글 신고에 열린 항목은 없고, legacy GitHub 열린 이슈 48건은 기존 번호 집합과 같다. GitHub 조회 도구의 수정 시각 부재로 본문 불변은 확인하지 못했다. 신고 조치·외부 답글은 하지 않았다.
- 기존 SQLD 가이드는 COUNT/NULL 개념을 설명하지만 연습 링크가 글 끝에 있었다. 새 글은 집계 전 행 조건과 집계 후 그룹 조건을 결제 주문의 원본 표·SQL·선택지로 설명한다. 실제 2026년 11월 SQLD 연습 세트와 관련 `HAVING` 문항으로 이어지며, SQLD 공식 기출이나 전체 출제범위를 재현한다고 주장하지 않는다.
- 별도 검토자는 PostgreSQL 18 공식 문서 링크, 표의 합계와 세 선택지, 시험 ID·11월 세트, 검색 메타데이터·렌더링 경로를 확인해 차단 결함이 없다고 보고했다. 표의 한국어 결제 상태와 SQL의 `paid` 값을 연결하는 문장을 추가했다.

## 검증과 출시
- 최종 `npm run check:local` 종료 코드 0. 타입 검사·lint·단위 186개·빌드·브라우저 120개·광고 시뮬레이션 6개가 통과했다. 브라우저 13개는 격리 PostgreSQL/Auth fixture가 없어 생략됐으며, 이 실행은 DB/Auth 흐름을 검증하지 않는다. 신규 글의 모바일 밝음/어두움 접근성, JavaScript 없이 글→실제 SQLD 연습 경로, 기존 가이드의 조기 링크를 확인했다.
- 검증된 routine 범위만 개발 브랜치에서 `master`로 반영해 Git push 한 번으로 출시한다. 실제 원격 커밋·production READY와 글·가이드·SQLD 연습 경로의 소수 읽기 결과가 확인되기 전에는 운영 반영으로 기록하지 않는다. 문제가 확인되면 해당 글·가이드 연결을 Git으로 되돌린다. 운영 DB와 기존 학습 데이터는 변경하지 않는다.

## 성과와 관측
GSC Web 전체기간 검색어와 기존 가이드 페이지에 SQLD 수요 신호가 각각 관측됐지만 두 차원을 같은 방문으로 묶을 수 없다. 새 글의 유입, 기존 가이드에서 실제 풀이 시작, 사용자 증가 및 수익 효과는 미측정이다. 배포 후 다음 완결일부터 28일 동안 두 페이지의 GSC 클릭/노출, GA4 자연검색 랜딩, 시험별 학습 시작을 각 원천에서 확인한다. 현재 GA4 `test_id` 수신·속성·시간대·최신 날짜 확정이 검증되지 않아 시험별 전환율과 인과효과를 계산하지 않는다.
