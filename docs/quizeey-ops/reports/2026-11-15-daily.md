# 2026-11-15 Quizeey PO 보고 — 조리 시험 경로 교정과 메이크업 위생 글

## 핵심 요약

양식·일식·중식·복어 URL이 한식 문제를 보여 주는 OPS-06 오류를 개발 브랜치에서 교정했다. 네 경로는 정확한 제공 안내와 명시적인 한식 이동 링크를 표시하고, 잘못된 시험 항목과 파생 URL은 목록·검색·사이트맵에서 제외한다. 한식 문항·채점·학습 저장키는 변경하지 않았다.

오늘의 원본 글은 [메이크업 위생 판단 연습](../../../web/src/components/MakeupHygieneArticle.tsx)이다. 기존 검색 의도와 실제 연습 세트를 확인하고 FDA·CDC 공식 원문에 근거한 설명과 자체 확인문제 두 개를 작성했다. 두 작업 모두 구현과 독립 검수는 완료했으며 필수 로컬 검증과 출시 상태는 아래 기록을 따른다.

## 운영 확인

- 이전 바리스타 글은 비공개 배포 영수증의 production READY 및 영향 경로 읽기 확인과 로컬/원격 커밋을 대조해 게시 완료로 정합화했다. 중복 글이나 추가 배포는 하지 않았다.
- 현재 DB 열린 문항·피드백 및 댓글 신고는 없다. 과거 미해결 항목은 해결 상태와 감사 기록이 일치해 비공개 상태를 정리했다. 역사적 정답·문구의 모호성은 별도 콘텐츠 과제로 유지하며 운영 DB 변경이나 신고 해결을 수행하지 않았다.
- legacy GitHub 열린 이슈는 기존 번호 집합과 같다. 조회 도구가 수정 시각을 제공하지 않아 최근 본문 변경 여부까지 확인했다고 주장하지 않는다. 공개 문서에 사용자 원문·식별자를 복제하지 않았다.
- report 입력은 기존 처리 manifest의 체크섬·크기와 일치해 신규 업로드가 없다. GA4 합계 차이·속성/시간대/확정일·시험별 학습 퍼널의 미확인 범위는 유지한다.

## 구현과 검수

- 네 잘못 연결된 시험 경로는 학습 데이터와 저장 컴포넌트를 실행하기 전에 안내를 반환한다. 일반 한식 링크 외에 검증된 회차·문항·페이지·문제 수를 보존하는 링크를 제공한다. 검색 메타데이터는 `noindex`, canonical은 해당 안내 기본 URL이다. 실제 한식 경로의 학습과 색인은 유지한다.
- 독립 검토자가 원천 보관 자료와 legacy 계약에서 별도 네 시험의 콘텐츠가 없음을 대조했다. 로컬 브라우저에서 네 경로 안내, generic 한식 이동, 검색 제외와 랜덤 세션 답안·북마크·점수·쿠키 보존 및 이어풀기를 확인했다.
- 한국 필터 GSC Web 검색 2026-08-09~11-08의 `메이크업 필기 기출문제`와 `/make-up-artist` 페이지에 관측이 있어 한국어 글을 선택했다. 수요가 작은 신호라는 한계를 유지하며 세부 마스카라 주제의 직접 검색 수요가 관측됐다고 주장하지 않는다. 기존 SQLD·SQLP·한식·바리스타·CCNA·3D 글과 의도가 겹치는 후보는 제외했다.
- 로컬 `/make-up-artist?verNbr=202610`에서 미용사(메이크업) 시험명과 실제 도구관리·손 위생·이상반응 경험의 기초 세 문항을 확인했다. 공통 미용 기초 세트이며 전체 시험 범위나 공식 기출이 아님을 본문과 CTA에 표시했다.
- 별도 검토자는 FDA의 마른 마스카라 폐기·물/침 첨가 금지·일회용 테스터 도구·자극 발생 대응과 CDC의 최소 20초 문지르기를 원문과 대조했다. 자체 문제 정답과 오답 이유가 근거와 일치했다. 미국 일반 보건 자료와 한국 시험 출제기준·국내 법규의 적용 범위를 구분했다. 검색 원본 수치의 독립 재분석은 이 콘텐츠 검토의 범위 밖이며 작성자의 비공개 근거 기록을 따른다.

## 검증과 출시

- 최종 전체 `npm run check:local` 종료 코드 0: 타입·lint·단위 186개·빌드·브라우저 131개·광고 시나리오 6개 통과. 격리 PostgreSQL/Auth fixture를 사용해 DB/Auth 검사도 실행했고 skip은 0개다. 모든 브라우저 검사는 localhost에서 수행했으며 광고 검사의 실제 외부 네트워크 요청은 0건이다.
- 첫 전체 실행은 타입·lint·단위 186개·빌드와 브라우저 130개를 통과했지만 기존 호환성 검사 한 개가 과거 기출 제목을 기대해 실패했다. 원천 fixture와 모든 경로·HTTP 상태·정확한 제목 검증을 유지하고 네 안내 제목의 기대값만 수정했다. 독립 검수 후 전체 명령을 처음부터 다시 실행한다. 서로 다른 실행의 통과 단계를 합산하지 않는다.
- 이 커밋 시점의 상태는 로컬 검증·독립 검수를 마친 Git release 후보이다. 개발 브랜치에서 검증한 트리를 `master`에 반영한다. push 이후 실제 커밋·production READY·영향 경로 읽기 결과는 비공개 `.modernization/quizeey-ops/2026-11-15-release-readback.json`과 `.md`에 기록하고 다음 실행에서 공개 상태를 정합화한다. 이 문서의 후보 상태만으로 운영 해결을 주장하지 않는다.
- 출시 범위 검수: 파생 36 URL은 독립 시험 36개가 아니라 잘못 연결된 네 경로의 회차·페이지 변형이다. URL을 안내로 유지하고 정상 한식 문제·학습 기록을 보존하는 복구 가능한 오류 수정으로, 독립 검토와 PO 모두 상시 승인된 저위험 PO 범위로 판단했다. 네 경로의 검색 유입 감소 가능성은 남는다. 최종 전체 검사 통과 후 `master` Git push 한 번으로 출시하고 실제 READY와 영향 경로의 소수 읽기 요청을 확인한다.
- 복구: 조리 안내·목록·색인 관련 변경을 되돌릴 수 있으며 학습 데이터는 변경하지 않는다. 글은 등록과 렌더링 연결을 되돌린다. 비공개 운영 자료와 생산 자격증명은 커밋하지 않는다.
