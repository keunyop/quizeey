# 2026-11-21 Quizeey PO 보고

SQLD의 UNION·UNION ALL과 NULL 중복 판정을 원본 입력·결과 표와 세 확인 문제로 설명하는 글을 준비했다. 실제 SQLD 11월 연습 경로와 본문 SQL 계산을 로컬에서 확인했다. 독립 검수와 전체 로컬 검사·출시 확인의 최신 상태는 [오늘 일지](../journal/2026-11-21.md)를 따른다. 효과는 미측정이다.

## 완료와 근거

- 현재 DB 전체 열린 신고와 legacy GitHub 전체 열린 이슈를 다시 읽었다. 새 변화가 없고 legacy 본문 전체도 전날 저장본과 같다. 미해결 문항의 현재 revision·본문·해설·공식 출처·보기·정답도 이전 적용 영수증과 일치했다. 수정 SQL 재실행이나 신고 종결은 하지 않았다.
- 보고서 입력은 모두 기존 manifest 체크섬과 같아 재처리하지 않았다. GA4 속성·시험별 수신·최신 확정 범위는 미확인으로 유지한다. 원본 지표와 사용자 원문은 비공개 기록에 둔다.
- 한국 필터 GSC의 실제 기간 2026-08-09~11-08에서 넓은 SQLD 연습 의도와 별도 페이지 근거를 확인했다. 최근 COUNT·집계·JOIN 글과 구분되는 학습 문제를 선정했으며 UNION 전용 검색 수요나 동일 방문 전환은 주장하지 않는다.
- [원본 글](../../../web/src/components/SqldUnionArticle.tsx)은 여섯 입력 행의 전체 열 UNION 3행·ALL 6행·번호만 UNION 2행을 비교한다. NULL 중복 제거와 일반 등호 비교, IS NULL 적용 대상, 반환 순서와 열/자료형 전제를 설명한다. 공식 PostgreSQL 18 원문을 확인하고 [문항 검수 기록](../../seo/sqld-union-review-20261121.md)에 정답·오답·revision·작성자/별도 검수자·범위를 남겼다.

## 검증과 출시 경계

실제 로컬 fixture에서 SQLD 정식 시험명·11월 20문항·첫 LEFT JOIN 문항과 선택지를 확인했다. 본문에서 실제 SQL 문자열을 추출해 격리 PostgreSQL 18의 읽기 CTE/SELECT로 행 수·NULL 판정 7가지를 재현했고 모두 통과했다. 운영 DB나 사용자 점수는 바꾸지 않았다.

JavaScript 비활성 읽기와 세 해설·정확한 11월 연습 연결, 모바일 양 테마 접근성·가로 넘침, 답 제출/해설 회귀를 통과했다. 독립 검수에 미해결 지적이 없고 최종 파일 다섯 개의 해시도 일치했다. 전체 `npm run check:local`은 종료 코드 0으로 완료됐으며 타입·lint·단위 190개·빌드·브라우저 145개·광고 시뮬레이션 6개 통과, 격리 DB/Auth 포함, skip 0이다. 실제 외부 광고 요청은 없었다. 로컬 fixture 결과이며 운영 DB/Auth 전체 설정의 검증을 뜻하지 않는다. 운영 READY와 제한된 읽기 확인은 일지의 후속 기록을 따른다.

검증된 작은 콘텐츠만 상시 승인 범위의 master Git push 한 번으로 반영한다. 영향 경로만 제한적으로 읽고 호스팅 회귀·자동 재배포는 하지 않는다. 복구는 해당 글·등록·연결 변경의 Git revert다.
