# 2026-11-10 국가·시험 유입 다변화 PO 보고

## 핵심 판단

국가별 이용과 일부 시험 랜딩의 집중을 확인했다. 기존 한국어 비조리 시험과 영어 콘텐츠를 먼저 활용하는 [30일 실행계획](../growth-plan.md)을 작성했다. 국가×시험 교차표가 없으므로 국가별 사용자와 시험별 세션을 연결하지 않았다. 상세 수치는 ignored private 보고서에 보관한다.

## 완료와 진행

- 새 일별·랜딩 CSV의 기간·속성 표시·숫자·연속 날짜를 확인했다. 보고서 총계는 서로 일치하지만 날짜/랜딩 행 합과는 차이가 있어 부분 기술 통계로만 사용한다. private 기준선과 처리 목록을 저장·재조회했고 차이는 미해결 검증 항목으로 유지했다.
- 한국어 홈은 기존 SQLD·3D프린터 안내와 정보처리기사, 영어 홈은 기존 AWS/Azure·SAT/U.S. GED·Ontario G1 안내로 이동할 링크를 검색창 아래에 추가했다. 전체 가이드 링크도 제공한다.
- 별도 검토자가 전달받은 실제 diff와 원문 경로 정의를 검토했고 차단 코드 결함은 발견하지 않았다. 검토자 자체 파일 접근은 도구 제한으로 실패했으므로 전달된 근거 범위를 명시한다. 전체 로컬 검사와 목적지 확인은 별도 완료조건이다.
- 현재 운영 DB 신고 집계와 기존 GitHub 미해결 목록을 재조회했다. 원문을 새 공개 파일에 복제하지 않았고 신고 처리·외부 메시지는 없다.

## 측정과 한계

해외 후보는 미국·캐나다의 기존 콘텐츠를 우선하고 국제 클라우드·네트워크 시험은 다른 국가의 관측 수요에 따라 확장한다. 일본·중국 현지 시험은 언어 수요·공식 범위·검수 가능성을 확인하기 전에는 제작을 확대하지 않는다. 국가별 세션/시험 시작, 개선 인과효과, 확정된 완결기간 성장률은 미측정이다.

## 릴리스와 검증

제품 변경은 **로컬 전체 검증 및 운영 release readback 완료**다. 두 홈의 전체 목적지·모바일·키보드·JavaScript 비활성 확인과 독립 코드 검토를 통과했다. 앞선 실행의 시간 초과를 조사한 뒤 긴 Texas 시나리오의 제한을 해당 테스트에만 조정하고, 블로그 7개 경로의 접근성 검사를 분리했다. November 320문항 단위 테스트는 단독 1.389초에 통과했지만 전체 병렬 실행에서는 5초 제한을 넘었다. 로컬 Vitest 워커 수를 2개로 제한한 후 183개 단위 테스트가 통과했으며, 별도 독립 검토도 통과했다. 병렬 실행 영향은 관찰됐으나 자원 부족 등 근본 원인은 확정하지 않는다.

최종 `check:local`은 종료 코드 0이다. typecheck·lint·단위 183개·fixture build·브라우저 97개·광고 회귀가 통과했다. 브라우저 13개 DB/Auth 테스트는 fixture 부재로 skip되어 그 흐름은 미검증이다. Commit `f7718a6`의 production Git deployment READY·운영 도메인 alias 및 한·영 홈의 HTTP 200/새 링크를 읽기 확인했다. 유입 효과는 미측정이다.
