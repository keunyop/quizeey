# 2026-11-22 Quizeey PO 보고

원두 보관 배치와 분쇄 시점·디개싱/산화를 설명하는 [바리스타 2급 학습 글](https://quizeey.com/blog/barista-2-coffee-storage-freshness)과 세 확인 문제를 게시했다. 개발 도구의 알려진 보안 권고도 지원되는 같은 주버전 업데이트로 수정했다. 독립 검수·최종 clean 설치·사후 감사·전체 로컬 검사 후 같은 커밋의 production READY·운영 도메인·세 경로 읽기 확인을 마쳤다. 세부 근거는 [오늘 일지](../journal/2026-11-22.md)에 보존했다. 학습 효과는 미측정이다.

## 완료와 근거

- 현재 DB 전체 열린 신고와 legacy GitHub 전체 열린 이슈 본문은 전날과 같다. 기존 해설 보강 문항의 revision·본문·해설·출처·보기·정답도 적용 영수증과 일치한다. 운영 DB 수정이나 신고 종결은 없다.
- 보고서 입력은 모두 기존 체크섬과 같아 다시 처리하지 않았다. GA4 속성·시험별 수신·최신 확정 범위는 미확인이다. 최근 production 배포의 1시간 error/fatal 집계에 반환된 그룹은 없었으며 해당 범위만의 관측이다.
- 한국 필터 GSC의 실제 2026-08-09~11-08 기간에서 바리스타 학습 의도와 별도 페이지 근거를 확인했다. 기존 추출비율 글 및 최근 다른 시험 글과 비교해 [원두 보관 글](../../../web/src/components/BaristaStorageArticle.tsx)을 선택했다. 보관 전용 검색 수요·동일 방문 전환은 주장하지 않는다.
- 세 보관 배치, 분쇄 시점, 디개싱·산화 구분을 원본 사례로 작성했다. [문항 검수 기록](../../seo/barista-storage-review-20261122.md)에 최종 정답 1/3/2·모든 오답 이유·작성/연구/독립 검수 역할과 범위를 남겼다. 시험 공식 기출·특정 보관기한이나 실제 품질실험으로 표시하지 않는다.

## 검증과 출시

로컬 fixture에서 바리스타 2급 정식 제목·11월 원본 20문항·첫 문제와 선택지를 확인했다. 블로그 목록→글과 세 해설→정확한 11월 연습→답 제출/해설 흐름과 JS 비활성 읽기·모바일 양 테마 접근성을 검증했다. 최종 보안 패치 후 전체 `npm run check:local`은 종료 코드 0이며 타입·lint·단위 190개·빌드·브라우저 147개·광고 시뮬레이션 6개 통과, 격리 DB/Auth 포함, 생략 0개다. 실제 외부 광고 요청은 없었다. 운영 DB/Auth 전체 설정의 검증과 구분한다. 독립 검수한 앱/회귀 다섯 파일과 의존성 두 파일의 최종 해시도 모두 일치했다.

개발 의존성 ESLint 10.15.0·typescript-eslint 8.73.0의 공식 지원 조합으로 minimatch를 11.0.9로 갱신했다. 강제 override와 운영 root 의존성 핀 변경은 없다. 독립 검수에서 발견한 기존 optional 잠금 항목의 pruning을 원래 세 항목으로 보완한 후 최종 clean npm ci가 종료 코드 0으로 통과했다. 같은 잠금 해시의 사후 Bulk 감사는 HTTP 200·알려진 권고 반환 없음이며 설치된 단일 11.0.9와 소비자 범위도 독립 확인했다. 모든 취약점의 부재를 보장하는 결과는 아니다. 패키지 변경 전에 실행 중이던 불완전한 검사는 중단·보존하고 최종 설치 상태에서 전체 검사를 다시 시작했다. 첫 실행은 통과로 세지 않는다.

검수한 변경을 `1c058bf8d8324c61db453ba422ebe40216542337`로 커밋하고 상시 승인 범위의 master Git push 한 번으로 반영했다. 원격 SHA와 같은 SHA의 production READY·quizeey.com 연결을 확인했다. Vancouver 11월 22일 18:51에 글·블로그 목록·바리스타 11월 연습을 GET 한 번씩 읽어 모두 HTTP 200과 예상 제목·본문·연결·문항을 확인했다. 별도 CLI/API 배포나 호스팅 회귀·광고 요청은 없다. 복구는 해당 글·등록·연결과 개발 의존성 핀/잠금 변경의 Git revert다. 최종 확인 문서는 별도 로컬 문서 커밋에 보존하고 다음 정기 출시에 포함한다.

## 성과와 남은 일

11월 22일 운영 확인을 마쳤으며 11월 23일~12월 20일 완결 28일 동안 GSC 글/검색어와 GA4 바리스타 학습 시작을 분리 관측한다. 속성·시험별 수신·시간대·집계 확정 전 개선율이나 완주율을 추정하지 않는다.

기존 GitHub 보안 알림 상세는 cache miss로 본문을 받지 못했으나, 공식 npm Bulk Advisory API의 한 읽기 감사와 실제 설치 대조로 개발 경로의 minimatch 10.2.6이 [moderate DoS 권고](https://github.com/advisories/GHSA-g3hv-75wg-m249)에 해당함을 확인했다. 현재 조사한 호출부에서는 악용에 필요한 optimizationLevel≥2 설정을 관찰하지 못했으며 운영 악용 가능성과 기존 알림의 동일성은 미확인이다. 지원되는 보안 수정은 위 검증을 따르며 GitHub 알림 종결을 선행 주장하지 않는다. 다음 큐는 기존 알림의 상태 확인, OPS-02 보관·정리 범위, GA4 수신·확정 범위, 게시 글의 완결 관측이다. 신고 종결·외부 답신·새 비용·파괴적 정리는 별도 승인 경계다.

오늘 작업을 완료하기 위한 소유자의 추가 조치는 없다. 기존 GitHub 알림 표시는 push 응답에도 남아 있어 사후 Bulk 결과와 별개로 상태 확인을 이어간다.
