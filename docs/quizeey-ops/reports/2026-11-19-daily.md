# 2026-11-19 Quizeey PO 보고

대기 중이던 CCNA IPv4 한국어 원본 5문항과 서로 다른 마스크의 설정을 점검하는 일일 글을 구현했다. 별도 검수자가 공식 근거·계산·오답·등록 코드와 회귀 범위를 독립 검토했다. 최종 전체 로컬 검사 후 Git 출시의 production READY·동일 SHA·도메인 연결과 영향 경로 네 곳의 읽기를 확인했다. 검색·학습 효과는 미측정이다.

## 완료한 작업

- 현재 DB 전체 열린 신고와 legacy GitHub 열린 이슈 본문을 다시 읽었다. 신고 대상의 원문·보기·정답·수정 시각도 전날 검토와 일치했다. 운영 DB 해설 보강은 별도 승인 대기로 유지하며 신고 종결·외부 답신은 하지 않았다.
- 모든 report 입력이 처리 manifest 해시와 같아 재처리하지 않았다. 신규 Google 자료가 없으며 시험별 학습 수신·속성·시간대·확정 범위의 공백은 유지한다.
- [한국어 원본 5문항](../../seo/ccna-ipv4-troubleshooting-questions-draft-20261117.md)을 별도 2026-11 회차로 등록했다. 게이트웨이·네트워크 범위·서로 다른 마스크·링크 주소·겹치지 않는 주소 배치를 다룬다. 첫 문항은 독립 검수 권고에 따라 같은 IP 서브넷 조건을 명시했다. 기존 2026-10 영어 23문항·식별자·저장 점수를 보존하고 영어 UI에서는 한국어 회차를 숨긴다.
- [새 일일 글](../../../web/src/components/CcnaTroubleshootingArticle.tsx)은 기존 계산 가이드와 다른 예제로 장비별 마스크 AND 결과, 실제 통신 결과와의 차이, 설정 점검 순서를 설명한다. 실제 로컬 CCNA 시험명·문항·보기를 확인한 한국어 5문항 경로로 연결했다. Cisco 공식 기출이나 한국어 시험 제공으로 소개하지 않는다.
- 기존 CCNA 글의 시험 언어 안내도 현재 Cisco 시험 페이지와 버전별 페이지의 차이를 날짜와 함께 구분하고 새 글로 연결했다. 발행일은 보존하고 수정일만 갱신했다.

## 검증과 출시 상태

최종 `npm run check:local` 전체 재실행이 종료 코드 0으로 완료됐다. 타입·린트·단위 190개·빌드·브라우저 141개·광고 시뮬레이션 6개가 통과했다. 격리 PostgreSQL/Auth fixture를 포함했고 생략은 0개다. 로컬 fixture 검증이며 운영 DB/Auth 설정 전체를 검증한 것은 아니다. 광고 시뮬레이션의 실제 외부 요청은 없었다.

첫 전체 실행은 새 JavaScript 비활성 테스트가 정식 시험명 대신 축약명을 기대해 실패했고 중단했다. 오류 문맥·실제 제목 원천을 독립 대조한 뒤 기대값만 정식 시험명으로 고쳤다. URL·회차·문항·언어 검증은 유지했고 별도 글 브라우저 검사 2개 및 전체 명령을 다시 통과했다. 실패 실행의 부분 결과를 출시 근거로 합치지 않았다.

검수 커밋 `f47550e`를 상시 승인 범위에서 master Git push 한 번으로 출시했다. 원격 SHA와 Git production 배포 SHA가 일치하며 READY·도메인 연결을 확인했다. 새 글·목록·한국어 5문항·기존 CCNA 글의 읽기 GET 네 건 모두 HTTP 200과 예상 내용을 확인했다. 운영 DB·신고 조치·추가 배포·호스팅 회귀는 하지 않았다. 복구는 새 콘텐츠와 연결의 Git revert다. 최종 운영 확인 문서는 로컬 커밋으로 보존하고 다음 정기 출시에 포함하며 기록만을 위한 두 번째 배포는 하지 않는다.

## 성과와 다음 순서

선정 근거는 한국 필터 GSC의 넓은 CCNA 문제 검색 의도와 별도 CCNA 연습 페이지 관측이다. 마스크 문제 해결이라는 세부 검색어 수요·동일 방문 전환·개선 효과는 미측정이다. 2026-11-20~12-17의 완결 28일 동안 GSC 글/검색어와 GA4 시험 학습 시작을 별도 관측한다. GA4 test_id 수신과 원천 확정 범위 확인 전 개선율이나 완료율을 추정하지 않는다.

다음 후보는 승인 대기 해설 보강의 운영 확인, OPS-02 비공개 보관·정리 범위 결정, GA4 시험별 수신·자료 확정 범위 확인, 게시한 글과 문항의 실제 학습 성과 관측이다. 기존 moderate 보안 알림은 현재 도구에 상세 조회 기능이 없어 확인 대기이며 취약점 내용을 추정하지 않는다. 진행 기록과 최종 상태는 [오늘 일지](../journal/2026-11-19.md)를 따른다.

## 소유자 승인 후 해설 DB 반영

소유자의 명시적 승인에 따라 준비된 해설·공식 출처 보강을 운영 DB에 반영했다. 현재 원본과 검수 SQL 해시를 재대조하고, 기존 격리 DB 검증 9건에 더해 정확한 전체 트랜잭션의 정상 적용/읽기와 신고·회차 변경 거부 3건을 통과했다. 독립 검토 후 한 번 적용했으며 commit 전 불변 확인과 commit 후 별도 DB 읽기를 마쳤다. 해당 문항 운영 페이지 GET 한 건도 HTTP 200과 새 해설·출처 출력이 확인됐다. 정답·보기·저장 점수는 유지했고 신고 종결은 별도 상태로 남긴다.

2026-11-19 소유자의 후속 지시로 검증된 정기 운영 반영은 운영 DB 수정까지 재승인 없이 진행한다. 루트 지침·운영 정책·PO 스킬에 기록했다. 위 본문의 해설 DB 승인 대기 표기는 이 후속 반영으로 완료됐으며, 다음 후보는 신고 종결의 별도 처리 범위, OPS-02 정리 결정, GA4 수신/확정 범위와 게시 콘텐츠 관측이다. 앱 재배포는 없고 이번 승인·운영 결과 문서는 다음 검증된 정기 출시에 함께 보존한다.
