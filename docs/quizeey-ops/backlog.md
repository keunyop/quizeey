## 30일 방향

2026-11-10 추가: Owner의 국가·시험 다변화 요청에 따라 OPS-03/OPS-05를 [유입 다변화 계획](growth-plan.md)으로 구체화했다. 새 일별·랜딩 자료는 제한적으로 처리됐으나 총계 차이와 국가×시험 차원·확정일은 미해결이다. GROWTH-01 기존 홈 학습 경로 개선은 로컬 전체 검사 통과 후 Git release readback 대기다. 수치와 입력 파일명은 private 보고서를 따른다. 아래 최초 계획은 배경이며 최신 실행 순서는 새 계획과 일지를 따른다.

- 1~7일: OPS-01 로컬DB 검증/검수, OPS-02 노출 분류, 최신 계정 자료 확보, GitHub 미해결 초기분류를 기존 기능과 대조. 릴리스 요청이 있으면 한 번의 검증된 release만 수행.
- 8~14일: 양식조리 중심 소규모 문항·해설 검수와 가장 큰 학습 불편 하나 수정. 정확도·학습시작/완료 기준선 확정. 새 문항 수 목표보다 검수 통과를 우선.
- 15~21일: 최근 블로그별 검색→학습 성과와 언어/기기 비교. 신규시험은 공식자료·외부수요·검수비용을 비교한 뒤 한 후보 파일럿만 검토. 신규 해외 수요를 기존 한국 수요보다 크다고 가정하지 않음.
- 22~30일: 수익·완료·재방문·속도·비용을 함께 평가. 표본이 충분한 경우만 한 가지 광고/사용성 실험 제안; 부족하면 기간 연장/보류. 실제 backup/restore와 비용 배분을 확인하고 다음달 방향 갱신.

실험은 문제/가설/범위/주지표/품질가드레일/기간·표본/중단·복구/판정으로 기록한다. GROWTH-01은 로컬 준비 상태이며 운영 실험은 아직 시작하지 않았다. 기존 balanced_v1은 무작위 A/B군으로 해석하지 않는다.
