# 테마·댓글·연습문항 개발 검증

2026-10-18 · America/Vancouver

상단 테마 전환, 라이트 화면의 대비 개선, 시험·문제별 댓글과 `2026-10` 자체 제작 연습 세트를 구현했다. 기존 기출의 ID·회차·통계·원본 파일은 변경하지 않았다. 초기 개발 검증은 로컬에서 수행했으며, 이후 소유자 승인으로 기존 댓글을 운영 DB에 반영했다. 운영 화면의 남은 설정은 아래에 기록한다.

## 화면과 학습

- 최초 테마는 기기 설정을 따르며, 선택한 테마는 저장하고 다른 탭·한국어/영어 페이지에 반영한다. 저장소 접근이 차단되어도 현재 탭에서는 전환할 수 있다.
- 페이지 배경, 카드, 입력창, 선택지, 채점 결과에 공통 테마 색상을 적용했다. 입력 테두리, 본문·보조 글자와 참고 링크 구분을 강화했다.
- 문제 댓글은 정답 확인 후 해설 안에서 표시한다. 댓글 작성란은 필요할 때 펼치며, 답글·수정 시 자동으로 열린다.
- 새 문항이 기존 묶음의 끝에 추가되어도 기존 시도·북마크·보기 순서를 유지한다. 기존 회차 필터와 20문항 단위 이어풀기를 유지한다.

## 문항

181개 시험에 각 3개, 총 543개의 문항 항목을 추가했다. 인접 자격의 공통 기초 개념을 공유하는 70개 주제 그룹, 210개 고유 질문으로 구성된다. 전체 모의고사나 실제 기출로 표기하지 않고 `2026-10` 회차와 `자체 제작` 배지를 표시한다. 모두 보기 4개, 정답 1개, 해설과 HTTPS 참고 링크를 포함한다.

[Q-net 공개문제](https://www.q-net.or.kr/cst006.do?id=cst00601&code=1204), [출제기준](https://www.q-net.or.kr/cst006.do?id=cst00601&code=1202), [AWS 공식 샘플](https://d1.awsstatic.com/training-and-certification/docs-dev-associate/AWS-Certified-Developer-Associate_Sample-Questions.pdf), 공급사 문서와 공개 교육 자료를 확인했다. 이번 추가분은 새로 작성한 연습문항이며, 새로운 실제 기출 회차를 수집·전재한 결과는 아니다. 참고 링크는 학습 범위 및 관련 개념을 확인하기 위한 것이다.

편집 원본은 `web/content/practice-2026-10.txt`, 생성 도구는 `tools/content/build_practice.py`다. 생성 결과에는 사용자 댓글이나 보관된 기출 원문이 들어가지 않는다. 새 문항은 기존 아카이브와 분리된 공개 코드 데이터로 제공되므로 배포 후 별도의 문항 DB 업로드가 필요하지 않다.

## 댓글과 ASiS 복원

시험 댓글은 `question_id = null`, 문제 댓글은 해당 문제 ID로 구분한다. 이름을 비워두면 익명으로 정규화한다. 제목 입력을 없애고 댓글 본문만으로 작성할 수 있게 했다. 기존 브라우저 소유권, 수정·삭제, 답글·신고 및 검토 후 공개 정책은 유지한다. 통신 실패 시 초안을 보존하고, 재시도에는 같은 요청 키를 사용하여 중복 등록을 방지한다.

실제 보관본에서 유효 문항에 연결된 댓글 **2,183개 / 630개 문제별 묶음**을 격리 로컬 DB에 복원했다. 원문, 작성자명, UTC 작성·수정 시간과 원본 대응 ID를 검증했다. 이전에 제외한 문제와 연결된 26개 글은 원본 백업에 보관하고 복원 공개 대상에서 제외했다. 이전 작성자명으로 신규 브라우저의 수정 권한을 추정하지 않는다.

복원 도구 `tools/migration/restore_comments.py --apply-local`은 원본의 해시를 검증한 뒤 고정된 로컬 테스트 DB에만 적용한다. SQL·상세 manifest는 기존 소유자 전용 백업 폴더에 저장한다. 재실행 시 기존 글과 검토 상태를 덮어쓰지 않는다. 실제 복원 데이터의 API 응답과 브라우저 표시도 확인했다. 공개 검증 증거는 [restored-comments-browser-evidence.json](restored-comments-browser-evidence.json)에 있으며 원문·작성자명은 포함하지 않는다.

## 검증 결과

- TypeScript, ESLint, Next.js 최적화 빌드 통과.
- Vitest 113개 통과. 새 문항 전체의 ID·선택지·정답·출처, 페이지 경계 및 기존 학습 기록 보존 검사 포함.
- 실제 Edge 브라우저 Playwright 28개 통과. 기존 경로·API·채점·복습·즐겨찾기·관리자 흐름과 새 댓글 분리·테마 저장/동기화·181개 시험의 새 회차 조회 포함.
- 320~1280px 화면 확인. 한국어/영어 및 라이트/다크 접근성 검사 통과.
- 복원 Python 검사 3개 통과. 합성 댓글 2,183개의 값 보존, 변경된 백업 거부, 재실행 및 anon/authenticated 공개 조회를 실제 격리 DB에서 검사하고 테스트 트랜잭션은 롤백했다.
- 실제 보관 댓글 복원 및 재실행 통과. 보호된 로컬 서버에서 실제 문제를 채점한 뒤 복원 댓글이 표시되고 새로고침 후에도 유지되는 것을 확인했다. 브라우저 오류·외부 요청 0건.

## 운영 반영 범위

소유자의 2026-10-18 운영 DB 반영 지시에 따라 `tools/migration/hosted_comments.py`로 댓글 2,183개와 문제별 묶음 630개를 Supabase 운영 프로젝트에 적재했다. 비공개 상태로 나눠 적재한 뒤 모든 원문·작성자명·ID·작성 및 수정 시간의 해시와 문항 연결을 검증하고, 한 트랜잭션에서 공개했다. 운영 `anon`과 `authenticated` 역할 모두 2,183개 댓글 및 630개 묶음을 조회한다. 이전 작성자의 신규 브라우저 소유권은 생성하지 않았으며, 시험 181개와 기존 문항 26,733개는 유지했다. 원본 백업과 DB 스키마는 변경하지 않았다.

운영 공개 API는 시험별·문제별 모두 `503 Forum unavailable`을 반환했다. 비밀값을 복호화하지 않은 Vercel 운영 환경변수 목록에서 `QUIZEEY_FORUM_BACKEND`, `QUIZEEY_TRUSTED_PROXY`, `QUIZEEY_ABUSE_HMAC_KEY`, `CRON_SECRET`, `QUIZEEY_SUPABASE_PUBLISHABLE_KEY`가 없는 것을 확인했다. 이번 DB 반영 작업에서는 배포 설정을 변경하거나 재배포하지 않았다. 사이트 댓글 표시는 이 설정을 완료한 배포에서 검증해야 한다.

운영 반영 및 공개 권한 증거는 [hosted-comments-import-evidence.json](hosted-comments-import-evidence.json)에 원문·작성자명 없이 기록했다. 운영 이전 도구의 값 변경 탐지와 미완료 배치 재개 차단을 확인하는 오프라인 검사 2개도 통과했다. 앞선 브라우저 검증 결과는 로컬 환경 기준이다.
